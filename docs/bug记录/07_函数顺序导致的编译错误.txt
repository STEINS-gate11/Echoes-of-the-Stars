《星空回响》Bug 记录 07 · 函数顺序导致的编译错误
============================================================

【现象】
编译报错：'setColor' / 'printemoji' / 'delay_with_Chinese' / 'clearbutter'
was not declared in this scope（未声明）

【定位过程】
编译器报错的位置在幕间那一块代码（play_pangpai / draw_the_pangbai / gaoliang / play_the_pangbai）。
但这些函数明明已经定义在文件里了。

【根本原因】
C 语言是顺序编译的。代码从上往下读，读到幕间函数时，
setColor、printemoji、delay_with_Chinese、clearbutter 这几个函数
还没有出现（定义在幕间代码的下面）。

编译器不认识它们，所以报错。

【解决方式】
把幕间那一整块代码（从 pangbai_alredy 数组开始，到 play_the_pangbai 函数结束）
整体剪切，粘到 printemoji 函数的下面、load_secene 的上面。

【教训】
C 语言里，函数 A 调用函数 B，B 必须定义在 A 的上面。
或者，在文件开头写函数声明（function prototype）。

如果代码有大量函数，最好的做法两种：
  方案 1：全部函数声明写在最前面（推荐）
  方案 2：把函数按"被调用关系"排序，被调用的放上面，调用的放下面

我们的项目一直没有写函数声明，全靠"手动排序"来保证编译通过。
这次幕间代码量大，贴到了错误的位置，就暴露了顺序问题。
