============================================================
Bug 11 · 结局函数的五处低级错误
============================================================

【时间】2026-07-30
【发生阶段】写结局函数时(show_the_jiejuDEzhimu / show_last_world / draw_the_ending_C_room / draw_the_Ade_tiantai / play_C_item)
【严重程度】编译错误 · 全都是低级错误 · 但都能让编译不通过


============================================================
【现象】
============================================================

编译时报错 · 5 个位置 · 都是"没注意"造成的:

  1. 宽字符字面量 L'\0' 中间有空格
  2. 语句末尾少分号
  3. 语句末尾少分号(在结构体绘制函数里)
  4. 变量名拼错(cur_chpter → cur_chapter)
  5. 函数只写了个壳 · 里面是空的


============================================================
【错误 1 · L 与字符字面量之间不能有空格】
============================================================

  错误代码:
    for (int j = 0; temp2[j] !=L '\0'; j++) {
                            ↑
                            L 和 '\0' 中间空了一格

  编译器行为:
    · L '\0' 会被识别为 "标识符 L" + " " + "字符字面量 '\0'"
    · 相当于 temp2[j] != L 后面还有个 '\0' · 语法错误

  正确写法:
    for (int j = 0; temp2[j] != L'\0'; j++) {
                                ↑
                                L 和 '\0' 紧挨着 · 一起构成宽字符字面量

  记住:
    · L"字符串"  · L 和 " 之间不能有空格
    · L'字符'   · L 和 ' 之间不能有空格
    · L 是"前缀标记" · 告诉编译器"下一个字面量是宽字符"
    · 中间隔空格 · 就不再是"前缀" · 变成两个独立 token


============================================================
【错误 2 · 语句末尾少分号 · text = lines_C】
============================================================

  错误代码:
    else {
        xianci_count = 5;
        text=lines_C            ← 少分号
    }

  编译器行为:
    · 会一直往下找 · 直到遇到 } 才报"expected ;"
    · 有时候报错行数是下一行 · 让人一时找不到

  正确写法:
    else {
        xianci_count = 5;
        text = lines_C;         ← 加分号
    }


============================================================
【错误 3 · 语句末尾少分号 · printemoji(L"@")】
============================================================

  错误代码:
    if (if_youren) {
        setColor(15);
        printemoji(L"@")        ← 少分号
    }

  正确写法:
    printemoji(L"@");


============================================================
【错误 4 · 变量名拼错 · cur_chpter】
============================================================

  错误代码:
    void draw_the_Ade_tiantai() {
        cur_chpter = 3;             ← 少了 a
        load_secene("rooftop.txt", ...);
    }

  编译器行为:
    · cur_chpter 未声明 · 报 "undeclared identifier"

  正确写法:
    cur_chapter = 3;

  教训:
    · 全局变量名尽量在你敲代码时用 IDE 自动补全
    · 拼错的变量 · 编译器不会智能纠错 · 得靠自己排查


============================================================
【错误 5 · 函数只写了个壳】
============================================================

  错误代码:
    void play_C_item() {
        system("cls");
        conver_node* p = head;
        // 空的 · 什么都没写
    }

  编译器行为:
    · 不报错 · 但函数不做任何事
    · 段 0 消散动画不会播 · 直接进段 1

  正确写法:
    void play_C_item() {
        system("cls");
        conver_node* p = head;

        while (p != NULL) {
            int x = 19, dot_count = 6;

            /* 按物品名查 x 和点数 */
            if      (wcscmp(p->name, L"⭐ 折纸星星")   == 0) { x = 19; dot_count = 6; }
            else if (wcscmp(p->name, L"📖 空白日记本") == 0) { x = 18; dot_count = 7; }
            /* ... 其他 16 个 ... */

            /* 1. 出现 · 1500ms */
            gotoxy(x, 12);
            setColor(6);
            printemoji(p->name);
            Sleep(1500);

            /* 2. 清 · 逐个打点 */
            clear(12);
            setColor(8);
            for (int j = 0; j < dot_count; j++) {
                gotoxy(x + j * 2, 12);
                printemoji(L"·");
                Sleep(150);
            }
            Sleep(500);

            /* 3. 清 · 下一件 */
            clear(12);
            Sleep(500);

            p = p->next;
        }

        Sleep(1000);
    }


============================================================
【教训】
============================================================

▌ 低级错误的规律
    这 5 个错误没有一个是"逻辑难" · 都是"手快没看清"
    · 打字滑了(空格 · 分号)
    · 拼写错了(chpter)
    · 复制粘贴后忘了写内容

▌ 减少低级错误的做法
    1. 每写一个函数 · 立刻编译一次(哪怕只是编译不运行)
       · 就能在下一个函数之前抓到本函数的错
    2. 用 IDE 的自动补全 · 而不是手动敲变量名
    3. 复制别人的示例代码后 · 逐行核对
       · 特别是空格 · 引号 · 分号 · 大小写

▌ 编译错误的定位
    C++ 编译器报错行数有时候是"下一行" · 因为它一直找到 } 才发现有问题
    · 如果报错行看起来没问题 · 往上翻 1-2 行找
    · 特别是"expected ;" 或 "expected }" 这类
