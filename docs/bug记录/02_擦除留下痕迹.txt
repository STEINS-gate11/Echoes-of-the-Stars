============================================================
Bug 02 · 擦除留下 @ 痕迹
============================================================

【发现时间】2026-07-09 · Day 2
【危险等级】⭐⭐（跟 Bug 01 是"连体双胞胎"）


============================================================
【一、现象】
============================================================

修完 Bug 01（数组清零）后，乱码没了，但是：
  - @ 走过的地方 全部残留 @
  - 走的越多，屏幕上 @ 越来越多
  - 场景背景没被破坏（不是乱码），但 @ 到处都是

屏幕现象（简化）：
     +---+---+---+---+         @@
     | . | * | . | * |         @@
     | * |\_/| * | . |        @@@@
     +---+---+---+---+       @@  @@
                     \  |  /   @@@@@ @
                      .-O-.   @@   @@@


============================================================
【二、根本原因】
============================================================

★ Bug 01 修好后：
  bg[y] 里没有场景字符的位置全都是 '\0'
  （memset 清零的效果）

★ 擦除代码：
  gotoxy(px, py);
  printf("%c", bg[py][px]);

★ 当 bg[py][px] == '\0' 时：
  printf("%c", '\0') → 什么都不打！
  或者打一个不可见字符

★ 结果：
  - 想擦掉 @，但没打任何东西
  - 旧 @ 就一直留在屏幕上

★ '\0' 在 C 里的特殊含义：
  '\0' = ASCII 0，是"字符串结束符"
  不是可见字符，printf 遇到它一般当"停止"处理
  所以 printf("%c", '\0') 打不出任何东西


============================================================
【三、解决方式】
============================================================

★ 擦除时判断：不是 \0 就打原字符，是 \0 就打空格

  gotoxy(px, py);
  if (bg[py][px] != '\0') {
      printf("%c", bg[py][px]);    // 场景内 → 恢复背景
  } else {
      printf(" ");                  // 空白区 → 用空格擦
  }


============================================================
【四、教训】
============================================================

★ Bug 01 + Bug 02 是连体的两个坑：
  - Bug 01 不修 → 走到空白 → 乱码"藹"
  - Bug 01 修了但 Bug 02 不修 → 走到空白 → @ 残留

★ 只有两个都修 → 才是真正正确的擦除逻辑

★ 教训：擦除逻辑要考虑 3 种情况
  1. 目标位置是场景字符 → 恢复原字符
  2. 目标位置是 '\0'（空白）→ 打空格
  3. 目标位置越界 → 什么都不做

★ '\0' 的性质：
  printf("%c", '\0') = 打不出东西
  printf("%s", "abc\0def") = 只打 "abc"（\0 后被截断）
  strlen("abc\0def") = 3（\0 是结束符）
  以后遇到"字符串莫名其妙短"的问题，多半是 \0 的锅


============================================================
【五、完整"擦除"逻辑模板】
============================================================

以后所有"擦除某位置"的代码，用这个模板：

  void eraseAt(int x, int y, const char bg[][50]) {
      gotoxy(x, y);
      if (bg[y][x] != '\0') {
          printf("%c", bg[y][x]);
      } else {
          printf(" ");
      }
  }


============================================================
【六、修复历程回顾】
============================================================

原始代码（有 Bug 01）：
  char bg[20][50];              // 未初始化
  // ...
  printf("%c", bg[py][px]);     // 空白位置打出垃圾字节 = "藹"乱码

加 memset 修 Bug 01：
  char bg[20][50];
  memset(bg, 0, sizeof(bg));    // ← 加这行清零
  // ...
  printf("%c", bg[py][px]);     // 现在空白位置是 \0
                                 // printf 遇到 \0 打不出东西
                                 // → 出现 Bug 02（@ 残留）

加判断修 Bug 02：
  char bg[20][50];
  memset(bg, 0, sizeof(bg));
  // ...
  if (bg[py][px] != '\0') {
      printf("%c", bg[py][px]);
  } else {
      printf(" ");                // ← 加这个分支
  }

现在两个 bug 都修好了 ✓
