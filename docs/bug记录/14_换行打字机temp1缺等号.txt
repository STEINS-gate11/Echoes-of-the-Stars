============================================================
Bug 14 · 换行打字机 temp1 缺等号
============================================================

【时间】2026-07-31
【严重程度】中等 · 换行位置错(ASCII 当 2 列算)
【位置】源.cpp 大概 1303 行 · delay_with_huanhang 里

============================================================
【现象】
============================================================

  void delay_with_huanhang(const wchar_t* text, int x, int y, int max_cols, int delay) {
      ...
      for (int i = 0; text[i] != L'\0'; i++) {
          int temp = 0;
          if (text[i] < 0x80) temp1;     // ← bug
          else temp = 2;
          ...
      }
  }

============================================================
【根本原因】
============================================================

  错把赋值运算符 "=" 写成了分号 ";"

  temp1 不是一个合法变量
  编译器会报"未声明的标识符 temp1"
  但这个写得太快,可能没发现

  实际效果:
    · temp 永远是初始值 0(因为没赋值)
    · else 分支:temp = 2
    · 所有字符都按 2 列算
    · ASCII 字符(英数空格)被多算 1 列
    · 提前换行

============================================================
【修复】
============================================================

  改成:
    if (text[i] < 0x80) temp = 1;
    else temp = 2;

  加 "=" 号

============================================================
【教训】
============================================================

  1. 打字时注意 "=" 和 ";"
  2. ASCII 字符应该是 1 列(英文/数字/空格/半角标点)
  3. 编译报错不要跳过,这个错误其实会编译失败
