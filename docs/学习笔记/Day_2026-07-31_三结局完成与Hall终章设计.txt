六、今天的教训
============================================================

  1. 写代码的最后几行要慢
     今天两个编译错都在"函数快写完的地方"
     前面 129 段都对,最后 1 段漏参数

  2. C++ 的"贴心特性"会变成静默 bug
     相邻字符串自动拼接 → 漏逗号不报错
     结构体未赋值字段自动 NULL → 少显示一行不崩

  3. == 只比地址
     wchar_t* / char* / 任何指针
     比内容必须 wcscmp / strcmp
     这是基本功,写快了容易忘

  4. 文本和动画要呼应
     独白说"走得很慢" → Sleep 从 200 改 500
     不是随便填数,是按剧情填

  5. static 是状态机的钥匙
     函数被外部循环反复调 → 变量必须 static
     否则每次都重置,动画永远停在第一帧

  6. 复用比重写好
     A 结局天台直接读 rooftop.txt
     只改配色 + 擦物品 + 加人物
     省 50 行代码

  7. 占位符 + 墙 + printemoji 是个好套路
     hall.txt 里 D 门用的就是这个
     终章标记照抄,不用发明新机制
