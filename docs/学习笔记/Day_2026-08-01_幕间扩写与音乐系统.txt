  19_终章触发的四处错.txt
    一次写完 hall 终章，四处都有错，四种不同类型：

    错 1 · 逻辑取反
      if (six_chapter_done()) return 0;   ← 少了 !
      完成了反而进不去
      教训：守卫子句一定带 !

    错 2 · 函数名当表达式
      fenqi_AB              ← 没括号
      编译器只给 warning，运行时什么都不发生
      教训：if 里只有一个标识符 → 检查是不是漏括号

    错 3 · 复制粘贴没改完
      else 分支也调 play_jieju_A()
      教训：if/else 两边逐行对比

    错 4 · 声明 int 但不返回值
      int fenqi_AB() 没有 return
      教训：写函数先想返回类型，没有就是 void

    ★ 四个里面有两个编译器完全不管

  20_MSVC连锁错误_37条只有1个真bug.txt
    编译报 37 条错误，全挤在十几行里
    实际是一个函数头坏了引发的雪崩

    ★ 决定性线索：C2365 "重定义"
      函数体里调用函数永远不会报重定义
      只有编译器认为你在函数外面才会报
      所以看到 C2365 → 上游函数头坏了

    下游错误码清单（不要单独查）：
      C2065 未声明的标识符
      C2365 重定义
      C4430 缺少类型说明符
      C2447 缺少函数标题
      C3861 找不到标识符
      C2059 语法错误 "}" "if"

    正确读法：
      1. 按行号排序，取最小的
      2. 往上看 1~3 行
      3. 修掉，重新编译
      4. 剩下的通常一起消失

六、真 gal 独白 vs AI 独白（今天学到的）
============================================================

  真 gal 的独白：
    - 说具体的东西（牌子、价钱、几点几分、第几排）
      细节不解释为什么重要
    - 不完整（想到一半停住，跳到别的事）
    - 不点题（让物件自己待在那）
    - 有废话（收银员换了人、面馆贴了转让的纸）
    - 偶尔一句很短（三行长句后突然五个字，那行才有重量）

  AI 独白的特征：
    - 排比整齐
    - 每段都收尾点题
    - 自问自答
    - 抽象词多，具体细节少
    - 功能性（解释设定、解释机制）

  ★ 项目原有的一句是最好的例子：
    "扭开关的时候「咔哒」一声，比我印象里应该有的声音要轻。"

    "比印象里要轻" 这种句子 AI 写不出来
    它太没道理了，但正因为没道理才像真的

  幕间扩写时新增页用的手法：
    - 具体到没道理的细节
      椅子响了四十一次
      借书卡最后归还日期是十月八号，不是他还的
      买了两瓶水，到收银台才想起来只需要一瓶
      一百二十六级台阶
      十七道折痕
    - 说完就走，不往回收
    - 有几页什么都没发生
      "今晚有点热。我坐了很久。"
      "楼下便利店的收银员换了一个。我也没跟她说过话。"

八、今天的教训
============================================================

  1. C2078 的行号告诉你查哪一维
     报在声明行 → 外层维度
     报在数据行 → 内层维度

  2. MSVC 报 N 条错误 ≠ 有 N 个 bug
     C2365 "重定义" 是最有价值的线索
     修最上面那条，剩下的一起消失

  3. 守卫子句一定带 !
     "如果没做完就返回" 而不是 "如果做完了"

  4. 函数名不加括号是合法表达式
     if (someFunc) 永远是 true
     编译器只给 warning

  5. if/else 两边要逐行对比
     复制粘贴改一半是最常见的错

  6. NULL 终止符占一个槽位
     声明的维度 = 实际内容数 + 1
     原代码留的余量是有意义的，扩容时不要精确吃掉

  7. wav 优先于 mp3
     MCI 的 repeat 对 mp3 不可靠
     修起来要动十几处等待循环

  8. 作者的话必须是作者写的
     我写的两版都不对
     第三版只做删减，效果最好

  9. 好句子不摆姿势
     "我为一个逗号找了很久 / 三年前只需要按一个键"
     聪明到能听见它在等鼓掌 → 删
