============================================================
【一、为什么要抽 loadScene】
============================================================

原本 main 里加载 prologue 场景的代码：

  fopen  →  memset  →  fgets 循环  →  fclose
  找 A B C 位置的双重循环
  画背景的循环
  高亮 A B、隐藏 C ? 的循环

这一大段将近 50 行，只做一件事：
"从文件读进一张 20×50 的地图，并显示到屏幕。"

如果要切换场景（比如从 prologue 切到 library），
只能把这 50 行复制粘贴一遍，改个文件名。

问题：
  - 加一层要复制 50 行
  - 6 层就是 300 行重复
  - 想改逻辑要改 6 遍
  - 场景越多，代码越乱

解决办法：抽成一个函数 loadScene，
以后切场景只需一行：

  loadScene("library.txt", bg, &ax, &ay, &bx, &by, &cx, &cy);


============================================================
【二、函数签名】
============================================================

void loadScene(
    const char* filename,
    char bg[20][50],
    int* ax, int* ay,
    int* bx, int* by,
    int* cx, int* cy);

参数含义：

  filename      要加载的 .txt 文件名
  bg            20×50 的地图数组，函数往里写数据
  ax, ay ...    输出参数：A B C 的坐标


============================================================
【三、为什么 int* 而不是 int】
============================================================

如果这样写：

  void loadScene(..., int ax, int ay, ...) {
      ax = 10;
      ay = 5;
  }

调用：

  int a = -1, b = -1;
  loadScene(..., a, b, ...);
  // a 还是 -1，b 还是 -1

原因：C 语言"传值"，函数拿到的是复制品，
     改了复制品不影响外面。

改成指针：

  void loadScene(..., int* ax, int* ay, ...) {
      *ax = 10;
      *ay = 5;
  }

调用时加 &：

  int a = -1, b = -1;
  loadScene(..., &a, &b, ...);
  // a = 10, b = 5

这次改的是"a 的地址所指向的内存"，
外面的 a 就跟着变了。


这就是"指针作为输出参数"的用法：

  一个函数想返回多个值时，
  用 return 只能返回一个，
  剩下的用指针参数往外输出。


============================================================
【四、& 和 * 一次记清楚】
============================================================

  &a    读作"a 的地址"       用在传参、赋值给指针
  *p    读作"p 指向的东西"    用在解引用取值/赋值

举例：

  int a = 5;
  int* p = &a;      // p 记住 a 的地址
  *p = 10;          // 改 p 指向的内容 → a 变成 10
  printf("%d", a);  // 输出 10


============================================================
【五、数组作为参数】
============================================================

  char bg[20][50]

在函数里作为参数写：

  void loadScene(..., char bg[20][50], ...);

注意：

  1. 数组名传入时，本身就是地址，不用加 &
     调用时直接写 bg，不写 &bg。

  2. 函数内部对 bg[i][j] 的修改会直接影响外面。

  3. sizeof(bg) 不能用！

     在 main 里：
        char bg[20][50];
        sizeof(bg)  →  1000（20 × 50）

     在 loadScene 里：
        sizeof(bg)  →  4 或 8（指针大小）

     因为数组作为参数时退化成指针，
     sizeof 得到指针本身的大小。

     所以函数里 memset 要写死大小：

        memset(bg, 0, 20 * 50);

     不能写：

        memset(bg, 0, sizeof(bg));  // 错！只清了 4 或 8 字节

【六、调用对比】
============================================================

抽出前（每换一层复制粘贴 50 行）：

  FILE* fp = fopen("prologue.txt", "r");
  memset(bg, 0, sizeof(bg));
  for (int y = 0; y < 20; y++) { fgets ... }
  fclose(fp);
  for (i,j 找 A B C 位置) ...
  for (画背景) ...
  for (高亮 A B、隐藏 C ?) ...

抽出后（每换一层一行）：

  loadScene("prologue.txt", bg, &ax, &ay, &bx, &by, &cx, &cy);


============================================================
【七、抽函数的常见套路】
============================================================

判断一段代码该不该抽成函数：

  1. 这段代码是否会重复出现？
     → 会，就该抽。

  2. 这段代码是否只做一件事？
     → 是，就抽得干净。

  3. 抽出后能不能起个动词开头的名字？
     → 能起清楚的名字（loadScene、drawDialog、
       checkWall），说明职责单一。

  4. 输入 / 输出是否清楚？
     → 输入放参数，输出用指针或 return。


============================================================
【八、一句话总结】
============================================================

  抽成函数：一个动作 = 一个函数
  int*     ：函数要"改到外面变量"就用指针
  &a       ：把 a 的地址传给指针参数
  *p = X   ：改指针指向的内存

loadScene 让"加载场景"变成一行，
是后面切换场景、写门厅系统的前置条件。
