============================================================
【一、字符含义速查】
============================================================

★ 墙（碰撞集）——— 走不过去 ———

  +     边框转角（窗户、桌子、相框转角）
  -     水平边框
  |     竖直边框 / 桌腿 / 台灯支架
  =     桌面结实边缘
  _     灯罩底 / 桌下阴影
  ( )   台灯灯泡（外壳）
  [ ]   门 / 窗棂
  #     远处建筑
  / \   望远镜三脚架 / 台灯光束 / 屋顶
  '     相框底角 / 屋顶尖


★ 可穿透 ——— 能走过 ———

  空格   空地板
  .      暗星（星空）/ 相框顶角（这里权衡）
  *      亮星
  ~      地毯
  A B C  物品（玩家走到旁边按 E 交互）

【二、代码碰撞判断】
============================================================

#include <string.h>

int isWall(char c) {
    return strchr("+-|=()_[]#/\\'", c) != NULL;
}

用法：
  if (c == 'd' && px < 47 && !isWall(bg[py][px + 1])) px++;

原理：
  strchr(字符串, 字符)
  在字符串里找这个字符，找到返回位置指针，找不到返回 NULL


============================================================
【三、字符的双重身份问题】
============================================================

★ 问题：
  同一个字符可能有不同"作用"，但代码无法区分。

★ 例子 · `.`
  - 星空里的 `.` = 暗星 → 应该能走
  - 相框顶角 `.-----.` 的 `.` = 相框的角 → 应该撞

★ 例子 · `O`
  - 台灯灯泡 `.-O-.` 的 `O` = 灯泡 → 应该撞
  - 场景里其他地方的字母 O = 装饰 → 应该能走

★ 代码怎么解决：
  只有一个规则，不能"看情况"判断。
  → 必须做取舍。


============================================================
【四、当前项目的取舍】
============================================================

★ 结论：`.` 是可穿透的，不加进碰撞集。

★ 理由：
  - 星空全场景都有 `.`，如果不能穿 → 玩家寸步难行 → 游戏没法玩
  - 相框顶角有个"漏洞"（能从 `.` 钻进相框上边）
  - 但不影响游戏进程，玩家几乎不会注意

★ 灯泡 O 同理不加：
  - 只在台灯出现一次
  - 玩家一般不会去屋顶那里
  - 加了会影响其他场景可能出现的字母 O


============================================================
【五、最终碰撞集】
============================================================

碰撞集（这 13 个字符是墙）：
  + - | = ( ) _ [ ] # / \ '

代码：
  strchr("+-|=()_[]#/\\'", c)

注意：
  - `\\'` 里 `\\` 是转义符表示一个 `\`
  - `\'` 是转义符表示一个 `'`


============================================================
【六、如何设计"能走的路径"】
============================================================

场景设计时要考虑：
  1. 玩家必须能走到每个物品旁边（±1 格）
  2. 玩家必须有路走到"下一层入口"
  3. 关键路径不能被墙包围
  4. 装饰性物品（相框、望远镜脚架）可以完整包围，
     但要留一个"缺口"让玩家能进

如果发现玩家走不到某个物品：
  → 检查该位置周围 4 格
  → 至少要有 1 格是"可穿透字符"

【七、strchr 函数】
============================================================

原型：
  char *strchr(const char *str, int c);

参数：
  str : 要搜索的字符串
  c   : 要找的字符

返回值：
  找到 → 指向该字符在 str 中的位置
  找不到 → NULL

例子：
  strchr("hello", 'e')    → 返回指向 "ello" 的指针（非 NULL）
  strchr("hello", 'z')    → NULL

用法：
  if (strchr("abc", ch) != NULL) {
      // ch 是 a、b、c 中的一个
  }
