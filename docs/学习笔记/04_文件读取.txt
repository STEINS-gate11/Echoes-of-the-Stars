============================================================
【一、fopen 打开文件】
============================================================

原型：
  FILE *fopen(const char *filename, const char *mode);

参数：
  filename : 文件名（可相对可绝对路径）
  mode     : 模式
    "r" = 读文本
    "w" = 写文本（覆盖）
    "a" = 写文本（追加）
    "rb" = 读二进制
    "wb" = 写二进制

返回值：
  成功 → 返回 FILE 指针
  失败 → 返回 NULL（文件不存在、没权限等）

★ 必须判空：
  FILE *fp = fopen("prologue.txt", "r");
  if (fp == NULL) {          // 或 if (!fp)
      printf("找不到文件\n");
      return 1;
  }


============================================================
【二、fgets 读一行】
============================================================

原型：
  char *fgets(char *str, int n, FILE *stream);

参数：
  str    : 读到哪里（一个字符数组）
  n      : 最多读 n-1 个字符（防止溢出，最后加 '\0'）
  stream : 从哪个文件读（fp）

行为：
  读一行 → 到 \n 为止（\n 也读进来）
  或读满 n-1 个字符
  自动在末尾加 \0（C 字符串结束符）

例子：
  char line[100];
  fgets(line, 100, fp);
  // line = "Hello\n\0"（如果文件第一行是 Hello）


============================================================
【三、fclose 关闭文件】
============================================================

原型：
  int fclose(FILE *stream);

用法：
  fclose(fp);        // 用完必须关

★ 不关会内存泄漏（长时间跑积累起来会崩）


============================================================
【四、二维数组读整个场景】
============================================================

场景是 20 行 × 每行 49 字符（+ '\0' 结束符 = 50）：

  char bg[20][50];

  FILE *fp = fopen("prologue.txt", "r");
  if (!fp) { printf("找不到\n"); return 1; }

  for (int y = 0; y < 20; y++) {
      fgets(bg[y], 50, fp);        // 每次读一行到 bg[y]

      // 去掉行尾 \n（重要！后面讲）
      int len = 0;
      while (bg[y][len] != '\0' && bg[y][len] != '\n') {
          len++;
      }
      bg[y][len] = '\0';
  }
  fclose(fp);

关键概念：
  bg[y]         = 第 y 行的字符串
  bg[y][x]      = 第 y 行第 x 个字符
  bg[y] 是字符串 → 可以直接 printf("%s", bg[y])

【五、遇到的坑 · 1 · 找不到文件】
============================================================

★ 症状：
  程序说"找不到 prologue.txt"，但文件明明在项目目录里

★ 原因：
  程序运行时的"当前目录"不是 .cpp 所在目录
  而是 exe 所在目录（比如 x64\Debug\）

★ 解决方式（3 种）：

方式 A · 用绝对路径：
  fopen("E:\\Project2\\Project2\\prologue.txt", "r");
  ★ 注意：\\ 是双反斜杠，代表一个 \

方式 B · 把文件复制到 exe 目录：
  x64\Debug\prologue.txt

方式 C · 改 VS 的工作目录（推荐）：
  1. 右键项目 → 属性
  2. 配置属性 → 调试
  3. 工作目录 改成：$(ProjectDir)
  4. 确定

  这样运行时的当前目录 = 项目根目录

【六、遇到的坑 · 2 · \n 换行符】
============================================================

★ fgets 会把 \n 一起读进来，除非手动去掉。

★ \n 的详细讲解见"03_换行符和gotoxy.txt"

★ 简单结论：
  读完一行后加这几行去掉 \n：

  int len = 0;
  while (bg[y][len] != '\0' && bg[y][len] != '\n') {
      len++;
  }
  bg[y][len] = '\0';


============================================================
【七、遇到的坑 · 3 · fopen 警告 C4996】
============================================================

★ 症状（VS 里）：
  'fopen': This function or variable may be unsafe.

★ 解决方式（3 种任选一）：

方式 A · 代码顶部加：
  #define _CRT_SECURE_NO_WARNINGS
  #include <stdio.h>

方式 B · 项目属性预处理器加：
  _CRT_SECURE_NO_WARNINGS
  （全局生效）

方式 C · 用微软的 fopen_s（不推荐，不通用）

【八、完整代码模板 · 加载场景】
============================================================

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <windows.h>
#include <conio.h>

void gotoxy(int x, int y) {
    COORD pos = {(SHORT)x, (SHORT)y};
    SetConsoleCursorPosition(GetStdHandle(STD_OUTPUT_HANDLE), pos);
}

void hideCursor() {
    CONSOLE_CURSOR_INFO info = {1, FALSE};
    SetConsoleCursorInfo(GetStdHandle(STD_OUTPUT_HANDLE), &info);
}

int main() {
    hideCursor();

    // 1. 打开文件
    FILE *fp = fopen("prologue.txt", "r");
    if (!fp) {
        printf("找不到文件\n");
        return 1;
    }

    // 2. 读入 20 行到 bg
    char bg[20][50];
    for (int y = 0; y < 20; y++) {
        fgets(bg[y], 50, fp);

        // 去 \n
        int len = 0;
        while (bg[y][len] != '\0' && bg[y][len] != '\n') len++;
        bg[y][len] = '\0';
    }

    // 3. 关闭文件
    fclose(fp);

    // 4. 用 gotoxy 画到屏幕
    for (int y = 0; y < 20; y++) {
        gotoxy(0, y);
        printf("%s", bg[y]);
    }

    gotoxy(0, 22);
    _getch();
    return 0;
}

【总结】
============================================================

加载一张场景需要：
  1. fopen 打开
  2. for + fgets 循环 20 次读入 bg 数组
  3. 每读一行去掉 \n
  4. fclose 关闭
  5. for + gotoxy + printf 画到屏幕

以后所有场景（library / rooftop / ...）都用这个模板。
