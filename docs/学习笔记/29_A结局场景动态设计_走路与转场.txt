二、draw_street_dongtai · 街道横向走路
============================================================

  void draw_street_dongtai() {
      int secene[4] = { 40, 25, 10, 2 };     // 四个停靠点的 x
      int cur_x = 44, cur_y = 14;            // 起点在最右
      gotoxy(44, 14);
      setColor(15);
      printemoji(L"@");
      Sleep(500);

      for (int i = 0; i < 4; i++) {
          int x = secene[i];
          while (cur_x != x) {               // 一步一步走到目标
              gotoxy(cur_x, 14);
              printf(" ");                   // 擦掉旧位置
              if (cur_x > x) cur_x--;        // 向左走
              gotoxy(cur_x, 14);
              setColor(15);
              printemoji(L"@");              // 画新位置
              Sleep(200);
          }
          switch (i) {                       // 到站说台词
          case 0:
              play_jiejju_conver(L"走过图书馆,它今晚关了灯。", 11, 28, 200);
              break;
          case 1:
              play_jiejju_conver(L"走过路口那家便利店,...", 11, 28, 200);
              break;
          case 2:
              play_jiejju_conver(L"走过学校的侧门,...", 11, 28, 200);
              break;
          case 3:
              play_jiejju_conver(L"你走到了天文台。", 11, 28, 300);
              break;
          }
      }
  }

  设计要点:

  1. 停靠点数组 secene[4] = {40, 25, 10, 2}
     从 44 开始往左走,依次停在 40、25、10、2
     每个停靠点对应街道上的一个建筑

     44 → 40:走 4 步  (图书馆)
     40 → 25:走 15 步 (便利店)
     25 → 10:走 15 步 (侧门)
     10 → 2 :走 8 步  (天文台)

     步数不均匀是有意的 —— 建筑之间的距离不一样

  2. 擦-移-画 三步
     gotoxy(cur_x, 14); printf(" ");     擦
     if (cur_x > x) cur_x--;             移
     gotoxy(cur_x, 14); printemoji(@);   画

     这三步不能颠倒,否则会留残影

  3. Sleep(200) 是步频
     200 毫秒一步 = 每秒 5 步
     太快看不清,太慢玩家等得烦

  4. y 固定 14
     街道是横向的,只有 x 变
     所有建筑都画在 y=5~11,人走在 y=14 的路面上

三、draw_stair_dongtai · 楼梯斜向走路
============================================================

  void draw_stair_dongtai() {
      int secene[10][2] = {                  // 二维数组,存 x,y 对
          {13, 13}, {15, 12}, {16, 11}, {17, 10}, {18, 9},
          {19, 8},  {20, 7},  {21, 6},  {22, 5},  {23, 4}
      };
      int cur_x = 13, cur_y = 13;
      gotoxy(cur_x, cur_y);
      setColor(15);
      printemoji(L"@");
      Sleep(500);

      for (int i = 0; i < 10; i++) {
          int x = secene[i][0];
          int y = secene[i][1];
          while (cur_x != x || cur_y != y) {  // ← 两个条件都要满足
              gotoxy(cur_x, cur_y);
              printf(" ");
              if (cur_x < x) cur_x++;         // 向右
              if (cur_y > y) cur_y--;         // 向上
              gotoxy(cur_x, cur_y);
              setColor(15);
              printemoji(L"@");
              Sleep(500);
          }
          Sleep(200);
      }
  }

  和街道版的三个差别:

  1. 二维数组 secene[10][2]
     街道只需要 x(y 固定 14)
     楼梯 x 和 y 都变,所以要存坐标对

  2. while 条件用 ||
     while (cur_x != x || cur_y != y)
     "只要有一个坐标没到就继续走"

     如果写成 && 会出错:
     假设 cur_x 先到了目标,cur_y 还没到
     && 会立刻退出,人停在半路

  3. 两个 if 并列,不是 else if
     if (cur_x < x) cur_x++;
     if (cur_y > y) cur_y--;

     这样一步能同时移动 x 和 y → 斜着走
     如果用 else if,一步只动一个方向 → 走楼梯梯形

     这里选斜走,因为楼梯本身就是斜的

  4. Sleep(500) 比街道慢
     街道 200 毫秒/步,楼梯 500 毫秒/步

     设计意图:
       "你今夜是自己一个人,你走得很慢"
       独白里明确说了走得慢,动画就要真的慢

     这是文本和动画的呼应

  5. 楼梯坐标和 draw_the_Ade_stair 里的台阶对齐

     draw_the_Ade_stair 画台阶:
       {23,4} {22,5} {21,6} {20,7} {19,8}
       {18,9} {17,10} {16,11} {15,12} {13,13}

     draw_stair_dongtai 走路径:
       {13,13} {15,12} {16,11} {17,10} {18,9}
       {19,8} {20,7} {21,6} {22,5} {23,4}

     完全一样,只是顺序反了(台阶从上往下画,人从下往上走)

四、show_the_jiejuDEzhimu · 转场字幕
============================================================

  void show_the_jiejuDEzhimu(const wchar_t* temp1, const wchar_t* temp2, int delay) {
      int len1 = 0;
      int len2 = 0;
      for (int i = 0; temp1[i] != L'\0'; i++) {
          len1++;
      }
      for (int j = 0; temp2[j] != L'\0'; j++) {
          len2++;
      }
      int x1 = 60 - len1;               // 居中公式
      int x2 = 60 - len2;
      if (x1 < 0) x1 = 0;
      if (x2 < 0) x2 = 0;
      setColor(15);
      gotoxy(x1, 11);
      delay_with_Chinese(temp1, 20);    // 主标题,白色
      setColor(8);
      gotoxy(x2, 13);
      delay_with_Chinese(temp2, 20);    // 副标题,灰色
      Sleep(delay);
  }

  居中公式 x = 60 - len:

    屏幕 120 列宽,中心在 60
    len 是字符数(不是列数!)
    中文一个字占 2 列,所以 len 个中文字占 2*len 列
    左边距 = 60 - (2*len)/2 = 60 - len

    这个公式只对纯中文正确
    混了 ASCII 会偏 —— 但转场字幕都是中文,没问题

  A 结局用了三次:
    show_the_jiejuDEzhimu(L"—— 两个月后 · 八月中旬 ——", L"街道 · 深夜", 2000);
    show_the_jiejuDEzhimu(L"—— 天文台 · 门口 ——", L"楼梯", 2000);
    show_the_jiejuDEzhimu(L"—— 天文台 · 天台 ——", L"夜风扑面", 2000);

  格式统一:
    主标题 —— 用 —— 包住,说地点/时间
    副标题 —— 不加装饰,说细节/氛围

  每次转场后固定三步:
    show_the_jiejuDEzhimu(...);
    system("cls");
    Sleep(500);
    draw_the_XXX();

  cls 是必须的 —— 否则上一个场景的画面残留

五、draw_the_Ade_tiantai · 复用已有场景文件
============================================================

  void draw_the_Ade_tiantai() {
      system("cls");
      char bg[20][50];
      int ax=-1, ay=-1, bx=-1, by=-1, cx=-1, cy=-1;
      cur_chapter = 3;                          // ← 关键:借第 3 章的配色
      load_secene("rooftop.txt", bg, &ax, &ay, &bx, &by, &cx, &cy);
      if (ax >= 0) { gotoxy(ax, ay); printf(" "); }    // 擦掉物品标记
      if (bx >= 0) { gotoxy(bx, by); printf(" "); }
      if (cx >= 0) { gotoxy(cx, cy); printf(" "); }
      clear(19);
      setColor(14);
      gotoxy(47, 0);
      printemoji(L"✦");                          // 加一颗织女星
      setColor(8);
      gotoxy(0, 18);
      printemoji(L"═══...═══");
      setColor(15);
      gotoxy(28, 14);
      printemoji(L"@");                          // 玩家站中间
  }

  设计思路:
    第 3 章的天台场景已经画好了(rooftop.txt)
    A 结局的天台和第 3 章是同一个天台
    直接复用,不用重新画

  要做三件事:
    1. cur_chapter = 3   让 get_senece_color 用第 3 章的配色
    2. 擦掉 A/B/C 物品标记 —— 结局里物品已经拿走了
    3. 加织女星 ✦ 和玩家 @

  这是"场景复用"的典型做法
  同一个地点,不同章节,只改装饰和人物位置

六、动态设计的三条原则
============================================================

  1. 文本说什么,动画就做什么
     独白说"走得很慢" → Sleep 从 200 改成 500
     独白说"一级一级" → 每级台阶单独一个停靠点
     独白说"她走得比你快" → 但这段没动画,因为是回忆

  2. 转场必须清屏
     show_the_jiejuDEzhimu 之后固定 cls + Sleep(500)
     不清屏 → 上个场景残留,画面撕裂
     Sleep(500) 是黑屏留白,让玩家喘口气

  3. 静态背景和动态角色分离
     draw_the_Ade_street()  画背景(建筑、路面、星空)
     draw_street_dongtai()  只动 @

     两个函数分开写
     背景画一次,角色动很多次
     不能每帧都重画背景 —— 会闪屏

============================================================
七、教训
============================================================

  1. while 条件的 || 和 && 要想清楚
     多个坐标要同时到达 → ||(只要有没到的就继续)
     写成 && 会提前退出

  2. 两个 if 并列 vs else if
     并列 → 斜着走
     else if → 阶梯走
     按场景选,楼梯选斜走更自然

  3. 停靠点数组是"剧情锚点"
     不是等分的,是按剧情需要放的
     图书馆、便利店、侧门、天文台
     每个点对应一句独白

  4. 复用场景文件省很多事
     A 结局的天台直接读 rooftop.txt
     只改配色 + 擦物品 + 加人物
     比重新画一份省 50 行代码
