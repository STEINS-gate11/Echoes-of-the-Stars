【一、选择 · Visual Studio vs VS Code】
============================================================

★ 最终选择：Visual Studio 2022 Community（免费）

Visual Studio (VS)：
  - 微软出的正规 IDE
  - 自带 MSVC 编译器（不用装 MinGW）
  - 调试器强
  - 智能提示好
  - 打开即用
  - 缺点：占空间大（5-10 GB）

Visual Studio Code (VS Code)：
  - 轻量代码编辑器
  - 要自己装 MinGW + 配置
  - 换行、编码坑多
  - 缺点：新手不友好

★ Windows C 大作业推荐用 Visual Studio


============================================================
【二、创建项目的步骤】
============================================================

1. 打开 Visual Studio
2. 选"创建新项目"
3. 搜"空项目"（Empty Project）→ 选 C++ 那个
4. 项目名：用英文，不用中文和《》
   例：Project2, XingKongHuiXiang
5. 位置：用英文路径
   ✅ E:\xingzhihueixiangDaima\
   ❌ E:\《星之回响》代码实现\
6. 点"创建"

【三、添加源文件】
============================================================

创建项目后，右边"解决方案资源管理器"会显示：
  Project1
  ├── 引用
  ├── 外部依赖项
  ├── 头文件
  ├── 源文件            ← 代码放这里
  └── 资源文件

添加代码：
  右键"源文件" → 添加 → 新建项 → C++ 文件(.cpp) → 输入名字


============================================================
【四、编译运行】
============================================================

★ Ctrl+F5  = 编译并运行（不调试）← 常用
★ F5       = 编译并运行（带调试）
★ F7 / Ctrl+Shift+B = 只编译不运行

按 Ctrl+F5 后会跳出黑色控制台窗口显示程序输出。


============================================================
【五、中文乱码解决方案】
============================================================

★ 症状：黑窗口显示 ??? 或 方块字

★ 原因：VS 默认不用 UTF-8 编码

★ 解决方式（VS 里）：
  1. 右键项目 → 属性
  2. 配置属性 → C/C++ → 命令行
  3. "其他选项" 里加：/utf-8
  4. 确定
  5. 重新编译

★ 或者代码里加一行（不用改属性）：
  #include <windows.h>
  int main() {
      SetConsoleOutputCP(65001);      // ← 让控制台支持 UTF-8
      // ...
  }


============================================================
【六、fopen 警告 C4996】
============================================================

★ 症状：编译提示
  'fopen': This function or variable may be unsafe.
  Consider using fopen_s instead.

★ 原因：微软觉得 fopen 不检查缓冲区，不安全

★ 解决方式（3 种任选一）：

方式 A · 代码顶部加一行：
  #define _CRT_SECURE_NO_WARNINGS
  #include <stdio.h>
  // ...

方式 B · 项目属性里全局关闭：
  1. 右键项目 → 属性
  2. C/C++ → 预处理器 → 预处理器定义
  3. 加一行：_CRT_SECURE_NO_WARNINGS
  4. 确定
  ★ 整个项目不用再加 #define

方式 C · 用 fopen_s（不推荐，不通用）


============================================================
【七、"一个项目只能一个 main()" 的坑】
============================================================

C/C++ 项目里，只能有一个 main() 函数。

★ 情况：你想学新东西，写练习代码
      但项目里已经有一个 main()
      直接加新 .cpp 会报错

★ 解决方式（3 种）：

方式 A · 排除旧代码：
  右键旧 .cpp 文件 → 从项目中排除
  文件还在磁盘，但不参与编译

方式 B · 建新项目：
  文件 → 新建 → 项目 → 空项目
  每个练习一个新项目

方式 C · 覆盖原代码：
  把旧代码删了，写新的（不推荐，会丢失历史）

★ 推荐方式 B：清爽，各学各的


============================================================
【八、工作目录的坑】
============================================================

★ 症状：程序 fopen("test.txt") 说找不到文件
      但 test.txt 明明就在项目目录里

★ 原因：程序运行时的"当前目录"不是 .cpp 所在目录，
        而是 exe 所在目录（比如 x64\Debug\）

★ 解决方式（VS 里）：
  1. 右键项目 → 属性
  2. 配置属性 → 调试
  3. "工作目录" 改成：$(ProjectDir)
  4. 确定

★ 这样运行时的当前目录 = 项目根目录 = 你放 test.txt 的地方
