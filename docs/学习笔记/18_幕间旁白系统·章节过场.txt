【一、需求】
============================================================

游戏需要两段"进入场景前播的东西"：

  章节过场：每次进场景都播（唯一例外：第一次进已经播过章节过场了）
           全屏黑底 + ═══ 装饰线 + 编号 + 章节名 + 短旁白
           玩家按空格继续

  幕间旁白：只在第一次进该场景时播
           书房底图 + 多页散文（打字机效果）
           玩家按 Enter 继续

两者关系：
  章节过场 = 骨架（一句话概括这章是什么）
  幕间旁白 = 血肉（长篇散文、细节、情绪）
  两者一起播，但互不重复


============================================================
【二、触发逻辑】
============================================================

标志位数组：
  int pangbai_alredy[7] = { 0,0,0,0,0,0,0 };
  每一位 = 0（没播过）或 1（播过）
  索引 0 = 开篇（标题→hall）
  索引 1~6 = 章 1~6

触发流程（get_to_the_secene 里）：

  if (pangbai_alredy[chapter] == 0) {
      play_pangbai(chapter);        // 章节过场（每次都播 → 但这里也只在第一次播）
      play_the_pangbai(chapter);    // 幕间旁白（只播一次）
  }

  注意：章节过场和幕间共用同一个标志位。
       因为两者总是同时出现，不需要分开记。

  get_to_the_hall 里只播开篇幕间（play_the_pangbai(0)），
  没有章节过场（因为 hall 不是一章）。

【三、数据结构】
============================================================

▌ 幕间底图（20 行 × 48 列，wchar_t 数组）

  const wchar_t* mujian_secene[20] = {
      L"                                                ",
      L"    .    .    .    .   ✦    .    .    .    .   ",
      ...
  };

  用宽字符数组（wchar_t），因为要放 emoji（⭐📖🖼✦）
  用 printemoji 输出，一次性打一整行

▌ 幕间文字（三维数组）

  const wchar_t* mujian_sanwen[7][10][8] = {
      // 7 段幕间
      // 每段最多 10 页
      // 每页最多 8 行文字
      // NULL 结尾
      { { L"第一行", L"第二行", ..., NULL }, { ... }, ... { NULL } },
  };

  好处：
    - 每段页数不同（8 页或 6 页），用 NULL 结尾不用另外记页数
    - 每页行数不同，也用 NULL 结尾
    - 文字用 wchar_t 支持中文

▌ 章节过场数据表

  struct mujian_zhuanhuan {
      const wchar_t* label;     // "序   幕" / "第 一 章"
      const wchar_t* name;      // "深    夜" / "初    遇"
      const wchar_t* pangbai1;  // 旁白第 1 行
      const wchar_t* pangbai2;  // 旁白第 2 行
  };
  mujian_zhuanhuan chapter_zhuanhuan[7] = { ... };

【四、高亮系统】
============================================================

每页翻页时，根据当前页面编号（pagenumber），把画面上特定的 emoji
改成特定的颜色，产生"画面跟着文字走"的视觉效果。

void gaoliang(int nowwerchapter, int nowwerpage) {
    // 织女星永远亮（金黄 14），除了医院段（暗成 8）
    gotoxy(23, 1);
    setColor(nowwerchapter == 4 ? 8 : 14);
    printemoji(L"✦");

    // 根据不同段、不同页，点亮不同物件
    switch (nowwerchapter) {
    case 0:  // 开篇
        if (nowwerpage >= 3) { /* 点亮台灯 */ }
        if (nowwerpage >= 4) { /* 点亮三件物品 */ }
        break;
    case 1:  // 序幕书房
        ...
    }
}

关键设计理念：
  - 织女星 = 她的化身 → 全篇永远亮，只有医院段暗掉
  - 其它物件 = 按叙事进度点亮
  - 用 switch 比 if-else 清晰，因为每段规则不同


============================================================
【五、函数封装】
============================================================

  draw_the_pangbai()        画底图（全灰 8，所有行用 printemoji 输出）
  gaoliang(chapter, page)      按页点亮对应物件
  play_pangbai(chapter)        播章节过场（有动画：渐入、逐字、打字机）
  play_the_pangbai(idx)        播幕间旁白（每页：画底图 → 高亮 → 打字机 → 等 Enter）

  关注点分离：
    - 画底图和点亮是两件事，分开写
    - 幕间播放和章节过场播放是两件事，分开写
    - 幕间只负责"播"，不负责"什么时候播"（触发由 get_to_the_secene 决定）

【六、本集新学的知识点】
============================================================

1. 三维数组存文字
   const wchar_t* arr[A][B][C]
   A = 段数，B = 每段页数，C = 每页行数
   用 NULL 结尾遍历，不需要记页数/行数常量

2. bool 标志位控制一次性触发
   int flag[N] = {0};
   if (!flag[idx]) { do_thing(); flag[idx] = 1; }

3. 高亮 = 在画底图之后，再画一次特定位置
   底图全灰 → 高亮把特定字符改成其他颜色
   每次翻页都重新画整张图，所以高亮会"重置"

4. 函数顺序
   C 语言是顺序编译的。如果函数 A 调用了函数 B，
   函数 B 必须定义在函数 A 的上面，或者先声明函数 B。
   否则编译器不认识 B，报错。

5. 结构体指针取地址
   用指针接结构体数组元素时，要加 & 取地址：
   struct 类型* 指针 = &数组名[下标];
