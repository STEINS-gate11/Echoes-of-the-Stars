▌ 文件读写
  1. fopen("xxx", "r")     打开文本文件（读）
  2. fgets(buf, size, fp)  读一行
  3. fclose(fp)            关闭文件

▌ 二维数组
  1. char bg[20][50] 声明
  2. bg[行][列] 访问
  3. bg[y] 是一整行的字符串（可以 printf %s）
  4. 数组必须 memset 清零，否则里面是垃圾数据

▌ 字符串处理
  1. \n 行尾符
  2. \0 字符串结束符
  3. fgets 读入的行末尾有 \n，要手动去掉

▌ 函数
  1. void 函数（无返回值）
  2. int 函数（有返回值）· 必须每条路径都 return
  3. 函数参数传递（按值传）
  4. 函数在 main 前面定义

▌ 主循环模式
  while (1) {
      1. 画玩家（gotoxy + printf）
      2. 等按键（_getch）
      3. 擦玩家（画回背景字符）
      4. 判断按键：q → break，e → 交互，wasd → 移动
  }

============================================================
【今天踩过的坑】
============================================================

▌ Bug 01 · 数组未初始化导致乱码
  症状：@ 走过后冒 "藹" 字乱码
  原因：char bg[20][50] 不自动清零，剩下的字节是内存垃圾
  修复：加 memset(bg, 0, sizeof(bg))

▌ Bug 02 · 擦除留下痕迹
  症状：修完 Bug 01 后 @ 走过留 @
  原因：printf("%c", '\0') 打不出东西，旧 @ 留下
  修复：擦除时判断 bg[y][x] == '\0' → 打空格

▌ Bug 03 · fopen 警告 C4996
  症状：VS 提示 "fopen 不安全"
  修复：项目属性 → 预处理器 → 加 _CRT_SECURE_NO_WARNINGS

▌ Bug 04 · 中文乱码
  症状：printf 显示 ??? 或 藹
  修复：项目属性 → C/C++ → 命令行 → 加 /utf-8

▌ Bug 05 · 找不到文件
  症状：fopen 返回 NULL，说找不到 prologue.txt
  修复：项目属性 → 调试 → 工作目录改成 $(ProjectDir)

▌ Bug 06 · 函数不 return 返回垃圾值
  症状：checkwall 没有默认 return 0，返回随机值
  修复：函数末尾加 return 0

▌ Bug 07 · else if 顺序错乱
  症状：擦玩家时特殊字符判断被通用条件挡住
  原因：!= '\0' 放前面把 A/B/C 都拦截了
  修复：特殊条件放前面，通用条件放后面

▌ Bug 08 · 变量名拼写错误
  症状：编译报错 "falgC 未定义的标识符"
  修复：改成 flagC


============================================================
【今天最大的收获】
============================================================

★ 收获 1：理解游戏主循环模式
  每一帧：画 → 等按键 → 擦 → 判断 → 更新状态
  这是所有 2D 游戏的基础模式，你现在完全掌握了

★ 收获 2：坐标系概念
  控制台 = 字符网格
  x = 列（水平）· y = 行（垂直）· y 越大越往下
  bg[y][x] 数组访问顺序跟 gotoxy(x, y) 顺序反过来
  （这个点让你崩溃过一次，但你现在通了）

★ 收获 3：状态机思维
  一个物品用一个变量（flagA / flagB / flagC）记录状态
  按状态分支决定下一步做什么
  C 的三段流程就是最简单的状态机（0 → 1 → 2 → 3）

★ 收获 4：擦除的哲学
  游戏动画的本质 = 画 + 擦 + 画
  擦要用 "背景原字符"，不能用空格（否则场景会破）
  永远考虑"擦的时候这里原本是什么"
