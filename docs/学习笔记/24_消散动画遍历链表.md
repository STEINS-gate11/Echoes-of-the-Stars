【核心代码(已写进源.cpp)】
============================================================

  void play_C_item() {
      system("cls");
      conver_node* p = head;
      int count = 0;

      while (p != NULL) {
          int y = 9 + count * 3;
          gotoxy(15, y);
          setColor(6);
          delay_with_Chinese(p->name, 28);
          Sleep(400);
          count++;

          if (count == 3) {
              Sleep(800);
              system("cls");
              Sleep(400);
              count = 0;
          }

          p = p->next;
      }

      if (count > 0) {
          Sleep(800);
          system("cls");
          Sleep(400);
      }

      Sleep(900);
  }

============================================================
【关键点 1 · 遍历 conver_node】
============================================================

  conver_node 是项目里的双向链表节点:
    struct conver_node {
        conver_node* prev;
        conver_node* next;
        const wchar_t* name;
        const wchar_t* line[5];
        int cur_chapter;
    };
    conver_node* head = NULL;
    conver_node* tail = NULL;
    int total_size = 0;

  head 和 tail 是全局变量(在源.cpp 里)
  玩家每拾一个物品,insert_tail() 就把它加到链表尾部

  遍历方式:
    conver_node* p = head;
    while (p != NULL) {
        ... 用 p->name ...
        p = p->next;
    }

============================================================
【关键点 2 · 每屏 3 个】
============================================================

  屏幕 30 行高 · 每屏用 3 行:
    count=0  → y=9   (第 1 个)
    count=1  → y=12  (第 2 个)
    count=2  → y=15  (第 3 个)

  三个出现后:
    Sleep(800);    /* 停 0.8 秒 · 让玩家看完 */
    system("cls"); /* 清屏 */
    Sleep(400);    /* 0.4 秒静默 */
    count = 0;     /* 重新计数 */

  边界处理:
    if (count > 0) {  /* 最后一屏不满 3 个 · 也要收尾 */
        Sleep(800);
        system("cls");
        Sleep(400);
    }

============================================================
【关键点 3 · 中压 28ms/字】
============================================================

  delay_with_Chinese(p->name, 28)
  · 每字 28ms · 和独白同步

  物品名约 5-7 字(emoji + 空格 + 中文)· 打字过程约 0.2-0.4 秒
  每个物品播完后停 400ms
  每屏 3 个约 1.5-2.5 秒
  每屏间隔约 1.2 秒

  15 件物品(全拾)约 30-40 秒
  少拾 · 更快

============================================================
【与设计稿的不同】
============================================================

  设计稿:每件物品出现 → 变 · → 变空白
  实际:每件物品出现 → cls(整屏消失)

  视觉效果:
    设计稿:字变成点 · 渐次消散
    实际:字打完 → 整屏黑 → 下一屏

  实际版本更狠 · 黑色全屏 · 真正的"没了"
