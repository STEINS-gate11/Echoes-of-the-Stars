《星空回响》学习笔记 · \n 换行符与 gotoxy
============================================================

【本笔记记录时间】2026-07-09 Day 2

【核心结论】
游戏里，所有换行都用 gotoxy 显式控制，不用 \n 自动换行。
这是做控制台游戏的黄金法则。


============================================================
【一、\n 是什么】
============================================================

\n 是一个字符（不是两个），叫"换行符"。

作用：告诉光标"跳到下一行开头"。

来源：
- 文本文件里每按一次 Enter，就多一个 \n
- 代码里的 "abc\n" 就是显式写了一个 \n

例子：
  文件里显示两行：
    Hello
    World

  实际存储的字符串是：
    Hello\nWorld\n
    （12 个字符：5 字母 + \n + 5 字母 + \n）


============================================================
【二、fgets 会把 \n 一起读进来】
============================================================

fgets 读一行 = 读到 \n 为止（\n 也读进来），或读满 buffer。

例子：
  文件第 1 行：Hello\n

  char line[50];
  fgets(line, 50, fp);

  读完后 line 里存：
    line[0] = 'H'
    line[1] = 'e'
    line[2] = 'l'
    line[3] = 'l'
    line[4] = 'o'
    line[5] = '\n'      ← 换行符被读进来
    line[6] = '\0'      ← C 字符串结束符（fgets 自动加）

★ 关键：\n 会跟着一起进来，除非手动去掉。


============================================================
【三、printf 遇到 \n 会真的换行】
============================================================

printf("Hello\nWorld");

输出：
  Hello
  World

原理：printf 从左到右打字，遇到 \n 就让光标"跳下一行开头"。


============================================================
【四、四种组合表】
============================================================

  bg[y] 有 \n?  |  printf 里加 \n?    |  换行几次  |  结果
  --------------+---------------------+-----------+---------
  有            |  不加 "%s"          |  1 次      |  ✅ 正好
  有            |  加 "%s\n"          |  2 次      |  ❌ 多空行
  无（手动去掉）|  加 "%s\n"          |  1 次      |  ✅ 正好
  无（手动去掉）|  不加 "%s"          |  0 次      |  ❌ 挤成一行

规律：
  换行次数 = bg[y] 里的 \n 数量 + printf 里的 \n 数量
  要正好 1 次换行 = 两处的 \n 加起来恰好 1 个


============================================================
【五、为什么游戏里"永远去掉 \n"】
============================================================

因为 gotoxy 能做 \n 不能做的事。

▌ \n 只能做的事：
  光标跳到下一行开头（只能往下，只能到行开头）

▌ gotoxy 能做的事：
  光标跳到屏幕任何位置（想去哪去哪）

▌ 游戏画面 vs 命令行：
  命令行程序：从上到下顺序打字，\n 够用
  游戏画面：任意位置画字符，必须用 gotoxy
    - 画 HUD 在右上角
    - 画物品在场景中间
    - 画玩家 @ 在任意位置
    - 玩家移动要"跳来跳去"

▌ 保留 \n 的问题：
  gotoxy(14, 13);           // 我想在 (14, 13) 打字
  printf("%s", bg[13]);      // 但 bg[13] 末尾有 \n

  结果：
  - 光标先到 (14, 13)
  - printf 打 bg[13] 内容
  - 打到 \n 时，光标自动跳到 (0, 14)  ← 你没让它跳，它自己跳了
  - 干扰下一次定位

▌ 没 \n 的好处：
  gotoxy(14, 13);
  printf("%s", bg[13]);      // 打完停在原位，不会乱跑

  光标"听话"，可以立刻用 gotoxy 跳到下一个位置精确定位。


============================================================
【六、代码模板 · 去 \n 的正确写法】
============================================================

// 读文件时去 \n
char bg[20][50];
for (int y = 0; y < 20; y++) {
    fgets(bg[y], 50, fp);

    // 找到 \n 的位置，用 \0 覆盖它
    int len = 0;
    while (bg[y][len] != '\0' && bg[y][len] != '\n') {
        len++;
    }
    bg[y][len] = '\0';       // 把 \n 变成 \0，字符串到这里结束
}

// 画屏幕时用 gotoxy 明确定位
for (int y = 0; y < 20; y++) {
    gotoxy(0, y);              // 精确指定"第 y 行第 0 列"
    printf("%s", bg[y]);       // bg[y] 没 \n，光标不会乱跑
}


============================================================
【七、比喻记忆】
============================================================

▌ \n = 写日记
  从上到下写，写完这行写下一行，回不去。

▌ gotoxy = 画画
  想在纸的哪里画就在哪里画。
  可以先画背景，再在中间加人物，再在角落写字。

▌ 做游戏 = 画画，不是写日记
  所以用 gotoxy，不用 \n。


============================================================
【八、一句话记住】
============================================================

游戏里：
  1. fgets 读入的每一行，末尾的 \n 都要去掉
  2. printf 里也不加 \n
  3. 换行、定位、跳位置 全部用 gotoxy 手动控制

这样光标永远"听话"，你想画哪画哪。
