============================================================
【一、什么是控制台】
============================================================

控制台（Console）= 黑框框那个窗口。
运行 C 程序跳出来的黑窗口就是它。

别名：
  - 命令行（Command Line）
  - 终端（Terminal）
  - CMD、PowerShell 都属于控制台

它是最古老的电脑界面：
  40 年前电脑没图形界面，只有控制台，
  敲字执行命令，屏幕打字回应你。


============================================================
【二、控制台是"字符网格"】
============================================================

★ 关键：控制台不是像素画布，而是字符网格。

    列 0   列 1   列 2   ...   列 79
行 0  ┌────────────────────────────────┐
行 1  │  H  e  l  l  o                 │
行 2  │                                │
行 3  │           @                    │  ← @ 在 (11, 3)
行 4  │                                │
 ...  │                                │
行 24 │                                │
     └────────────────────────────────┘

尺寸：通常 80 列 × 25 行 = 2000 个格子
每格：只能塞一个字符（字母/汉字/@/#/*）

对比像素画布：
  控制台：字符为单位（80×25）
  像素：  1920×1080 之类，能画任何形状

★ 你的游戏 = 用字符组成的画


============================================================
【三、坐标系规则】
============================================================

★ 关键点：
  - 原点 (0, 0) 在 左上角
  - x = 列号（0 到 79，从左到右）
  - y = 行号（0 到 24，从上到下）
  - y 越大越往下（跟数学坐标反了）

例子：
  (0, 0)      = 左上角
  (79, 0)     = 右上角
  (0, 24)     = 左下角
  (40, 12)    = 屏幕正中间

你的游戏：
  场景 = 20 行 × 48 列
  y 用 0 到 19
  x 用 0 到 47


============================================================
【四、控制台能做什么 · 不能做什么】
============================================================

✅ 能做：
  - 在指定位置打字符
  - 改字符颜色（16 种）
  - 改背景颜色
  - 读键盘
  - 播 beep 声音
  - 改窗口标题
  - 改窗口大小

❌ 不能做（或很难）：
  - 画像素画（真圆形/曲线）
  - 播图片 / gif
  - 播音乐（要用另外的 API）
  - 鼠标交互
  - 弹窗


============================================================
【五、为什么用控制台做游戏】
============================================================

优点：
  1. 零依赖（不用装 SDL/OpenGL/Qt）
     只要 stdio.h + windows.h 就能开始
  2. 代码超简单
     画一个 @ 只要 2 行
  3. 入门神器
     C 大作业几乎都用控制台
  4. 独特美感
     ASCII art + 打字机 + 有限色彩 = 复古氛围

★ 你的《星空回响》正是利用了这个美学：
  - ASCII 星空 = 复古电影感
  - 打字机效果 = 逐字沉淀的仪式
  - 16 色 = 克制的美


============================================================
【六、4 个必学的 Windows API】
============================================================

做控制台游戏只需要 4 件事：
  1. 让 printf 打到指定位置 → gotoxy
  2. 让字变颜色 → setColor
  3. 隐藏系统光标 → hideCursor
  4. 读键盘 → _getch

★ 用这 4 个 + printf，游戏 90% 的画面都能做出来


------------------------------------------------------------
函数 1：gotoxy(x, y) — 光标跳到 (x, y)
------------------------------------------------------------

void gotoxy(int x, int y) {
    COORD pos = {(SHORT)x, (SHORT)y};
    SetConsoleCursorPosition(GetStdHandle(STD_OUTPUT_HANDLE), pos);
}

用法：
    gotoxy(10, 5);       // 光标到第 10 列、第 5 行
    printf("@");         // 在那里画个 @

★ 记住：这 4 行代码永远抄下来用，别理解，别改。


------------------------------------------------------------
函数 2：setColor(c) — 让接下来的字变颜色
------------------------------------------------------------

void setColor(int c) {
    SetConsoleTextAttribute(GetStdHandle(STD_OUTPUT_HANDLE), c);
}

颜色数字 0-15：
  0  黑
  1  深蓝
  2  深绿
  3  深青
  4  深红
  5  深紫
  6  棕
  7  灰白（默认）
  8  深灰
  9  亮蓝
  10 亮绿
  11 亮青       ← 提示文字用
  12 亮红       ← 记忆值告警用
  13 浅紫       ← Vega 用
  14 金黄       ← 主线金色用
  15 亮白       ← 一般文字

用法：
    setColor(14);
    printf("金色字");
    setColor(15);
    printf("白色字");


------------------------------------------------------------
函数 3：hideCursor() — 隐藏系统光标
------------------------------------------------------------

void hideCursor() {
    CONSOLE_CURSOR_INFO info = {1, FALSE};
    SetConsoleCursorInfo(GetStdHandle(STD_OUTPUT_HANDLE), &info);
}

作用：把闪烁的下划线光标 _ 隐藏掉。

用法：在 main() 开头调一次即可。


------------------------------------------------------------
函数 4：_getch() — 读一个键（不用回车）
------------------------------------------------------------

#include <conio.h>

char c = _getch();       // 阻塞，等按键，返回按的字符

跟 getchar() 的区别：
                       getchar()   _getch()
  需要回车              是          否
  屏幕显示按下的键      是          否
  用途                  普通程序    游戏

附赠：_kbhit() = 检查有没有键被按下（不阻塞，返回 0 或非 0）


============================================================
【七、为什么不需要学其他 Windows API】
============================================================

Windows 有几百个 API，为什么只学这 4 个？

因为做控制台游戏只需要：
  1. 写字到屏幕指定位置       → gotoxy
  2. 让字变颜色                → setColor
  3. 隐藏系统光标              → hideCursor
  4. 读键盘                    → _getch

其他 API：
  Sleep(ms) — 会用就行（暂停 ms 毫秒），不用理解
  GetTickCount() — 会用就行（毫秒数），不用理解
  mciSendString — W8 加分项才学（播 BGM）
  多线程、网络、注册表、GUI... — 你这辈子做这个游戏都用不到
