============================================================
【一、为什么只画上下横线】
============================================================

如果画左右竖线，会遇到这些问题：

  1. 中文一个字通常占 2 个显示列，控制台不能保证精确对齐
  2. Emoji 大部分占 2 列，但个别字体只占 1 列
  3. 竖线位置一旦对不齐，画面就会出现豁口

只画上下横线之后：

  - 上下横线用纯 ASCII 字符 -，永远等宽
  - 中文和 emoji 只出现在上下横线之间，不再影响画面结构
  - 视觉上仍然形成一个"框"


============================================================
【二、draw_dialog 函数】
============================================================

void draw_dialog(int x, int y, int length, int width) {
    gotoxy(x, y);
    setColor(8);

    for (int i = 0; i < length; i++) {
        printf("-");
    }

    gotoxy(x, y + width - 1);

    for (int i = 0; i < length; i++) {
        printf("-");
    }
}

参数含义：

  x         对话框左上角的列
  y         对话框左上角的行
  length    横线的长度（宽度）
  width     对话框总高度

行为：

  第一步：在 (x, y) 画一条横线
  第二步：在 (x, y + width - 1) 再画一条横线

例如：

  draw_dialog(0, 21, 60, 5);

含义：

  从 (0, 21) 开始
  长度 60 列
  高度 5 行
  上横线在第 21 行
  下横线在第 25 行


============================================================
【三、cleararray 函数】
============================================================

void cleararray(int x, int y) {
    for (int i = x; i < x + y; i++) {
        clear(i);
    }
}

参数含义：

  x   起始行
  y   要清除的连续行数

例如：

  cleararray(21, 5);

含义：

  清除第 21、22、23、24、25 行


============================================================
【四、对话框内部布局】
============================================================

以对话框位置 (0, 21) + 长度 60 + 高 5 为例：

  行 21   上横线（灰色 8）
  行 22   姓名栏（金色 14 或紫色 13）
  行 23   正文（白色 15）
  行 24   右下角继续标记 ▼（灰色 8）
  行 25   下横线（灰色 8）

姓名栏和正文都相对左边留 2 格边距：

  gotoxy(2, 22);
  gotoxy(2, 23);

继续标记贴近下横线右侧：

  gotoxy(55, 24);


============================================================
【五、对话流程六步】
============================================================

拾取物品时的对话流程，固定按顺序执行：

  1. cleararray(21, 5);          清除旧对话
  2. draw_dialog(0, 21, 60, 5);  画上下横线
  3. gotoxy + setColor + printWideAll(姓名栏)
  4. gotoxy + setColor + delay_with_Chinese(正文)
  5. gotoxy + printf("▼")        继续标记
  6. clearbutter(); _getch();    等待玩家按键
  7. 修改 bg 与场景（如抹掉物品）
  8. cleararray(21, 5);          清掉整个对话框
  9. 设置对应 flag（如 flagA = 1）


============================================================
【六、姓名栏与正文的函数分工】
============================================================

  姓名栏     printWideAll(整段一次性输出)
  正文       delay_with_Chinese(逐字动画)

分工理由：

  - 姓名栏可能包含 emoji（如 ⭐ 📖 🖼），
    某些 emoji 在 UTF-16 中占 2 个 wchar_t（代理对），
    逐字输出会拆开。一次性整段输出可以避开这个问题。
  - 正文一般是纯中文和标点，不含 emoji，
    可以放心逐字输出，营造打字机气氛。


============================================================
【七、颜色约定】
============================================================

  8   灰色      对话框上下横线、继续标记、按键提示
  14  金色      物品姓名栏（主线物品）
  13  紫色      C 的察觉 / 显形提示
  15  白色      对话正文
  4   红色      C 显形之后的问号


============================================================
【八、为什么不做左右两条竖线】
============================================================

即使强行画竖线，需要处理很多问题：

  1. 每一行必须精确算列数
  2. 中文占 2 列会破坏对齐
  3. 后续玩家 @ 走位可能覆盖竖线
  4. 每次对话都重画竖线，性能和代码复杂度上升

上下横线加姓名栏的写法：

  - 结构清晰
  - 对齐稳定
  - 代码短
  - 视觉仍然像一个对话框


============================================================
【九、一句话总结】
============================================================

对话框 = 上下横线 + 姓名栏 + 正文 + 继续标记 + 整块擦除。

用两个工具函数：

  draw_dialog     画横线
  cleararray      擦对话区

保证：

  - 中文和 emoji 不撞对齐
  - 每条对话流程固定
  - 视觉一致
