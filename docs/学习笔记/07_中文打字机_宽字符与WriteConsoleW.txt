============================================================
《星空回响》学习笔记 07 · 中文打字机：宽字符与 WriteConsoleW
============================================================

【学习时间】2026-07-21

【学习前提】
- 已理解英文打字机循环；
- 已理解 printf、fflush(stdout)、Sleep(delayMs)；
- 当前没有学习位运算；
- 本方案不判断 UTF-8 字符占几个字节，而是使用 Windows 宽字符接口。


============================================================
【一、为什么英文能逐个 char 输出】
============================================================

英文字符串：

  const char* text = "ABC";

内存里大致是：

  text[0] = 'A'
  text[1] = 'B'
  text[2] = 'C'
  text[3] = '\0'

每次执行：

  printf("%c", text[i]);

正好输出一个完整英文字符。


============================================================
【二、中文为什么不能简单逐个 char 输出】
============================================================

在 UTF-8 编码中，一个汉字通常占 3 个字节。

例如字符串：

  const char* text = "星";

内存里大致是：

  text[0] = "星"的第 1 个字节
  text[1] = "星"的第 2 个字节
  text[2] = "星"的第 3 个字节
  text[3] = '\0'

如果每次只执行：

  printf("%c", text[i]);

就可能把一个完整汉字拆成三个字节分别输出，导致乱码。

核心区别：

  英文：1 个字符通常对应 1 个 char
  中文：1 个字符可能对应多个 char 字节


============================================================
【三、当前方案：使用 Windows 宽字符接口】
============================================================

为了不提前学习 UTF-8 位运算，可以使用：

  wchar_t
  L"中文宽字符串"
  WriteConsoleW

基本函数：

void typewriterChinese(const wchar_t* text, int delayMs) {
    HANDLE output = GetStdHandle(STD_OUTPUT_HANDLE);

    for (int i = 0; text[i] != L'\0'; i++) {
        DWORD written;

        WriteConsoleW(
            output,
            &text[i],
            1,
            &written,
            NULL
        );

        Sleep(delayMs);
    }
}

调用：

  typewriterChinese(L"你拿起那颗星星。", 80);


============================================================
【四、wchar_t 是什么】
============================================================

普通字符类型：

  char

宽字符类型：

  wchar_t

当前可以简单理解为：

  char      适合英文 ASCII 字符和原始字节
  wchar_t   在 Windows 下更方便表示中文字符

函数参数：

  const wchar_t* text

表示：

  text 指向一串只读宽字符。


============================================================
【五、L"中文" 是什么】
============================================================

普通字符串：

  "中文"

类型大致为：

  const char*

宽字符串：

  L"中文"

类型大致为：

  const wchar_t*

因为 typewriterChinese 的参数是：

  const wchar_t* text

所以调用时必须写：

  typewriterChinese(L"中文", 80);

不是：

  typewriterChinese("中文", 80);


============================================================
【六、WriteConsoleW 是什么】
============================================================

WriteConsoleW 是 Windows 控制台的宽字符输出函数。

函数名最后的 W 表示：

  Wide（宽字符版本）

它可以直接把宽字符写到 Windows 控制台，不需要手动判断一个汉字由几个 UTF-8 字节组成。

本项目中只需要知道这几个参数：

  WriteConsoleW(
      output,       // 输出到哪个控制台
      &text[i],     // 从当前宽字符的地址读取
      1,            // 本次输出 1 个宽字符
      &written,     // 接收实际输出字符数
      NULL          // 当前不用的保留参数
  );


============================================================
【七、HANDLE output 是什么】
============================================================

代码：

  HANDLE output = GetStdHandle(STD_OUTPUT_HANDLE);

含义：

  获取标准输出设备（控制台屏幕）的句柄，保存到 output。

简单理解：

  output = 控制台屏幕的"把手"

后续 WriteConsoleW 使用这个把手，告诉 Windows：

  把文字写到这个控制台屏幕上。


============================================================
【八、DWORD written 是什么】
============================================================

代码：

  DWORD written;

作用：

  接收这一次实际写出了多少个宽字符。

当前项目不需要主动使用 written 的值，但 WriteConsoleW 要求提供这个地址。

例如成功输出 1 个宽字符后：

  written 通常等于 1


============================================================
【九、&text[i] 是什么】
============================================================

  text[i]

表示当前宽字符本身。

  &text[i]

表示当前宽字符在内存中的地址。

WriteConsoleW 需要知道：

  从内存的哪个位置读取要输出的字符

因此传入：

  &text[i]


============================================================
【十、为什么这里不用 fflush(stdout)】
============================================================

英文版：

  printf("%c", text[i]);
  fflush(stdout);

printf 通过标准输出流 stdout 工作，可能使用输出缓冲区，所以主动 fflush 能保证字符立即显示。

宽字符版：

  WriteConsoleW(...);

WriteConsoleW 直接调用 Windows 控制台接口写入控制台，因此这里不依赖 printf 的 stdout 缓冲。

当前方案不需要：

  fflush(stdout);


============================================================
【十一、Sleep(delayMs) 仍然负责节奏】
============================================================

每次输出一个宽字符后：

  Sleep(delayMs);

例如：

  typewriterChinese(L"你好", 100);

运行过程：

  输出 "你"
  暂停 100ms
  输出 "好"
  暂停 100ms
  遇到 L'\0'，结束


============================================================
【十二、最小中文打字机练习】
============================================================

#include <windows.h>

void typewriterChinese(const wchar_t* text, int delayMs) {
    HANDLE output = GetStdHandle(STD_OUTPUT_HANDLE);

    for (int i = 0; text[i] != L'\0'; i++) {
        DWORD written;

        WriteConsoleW(
            output,
            &text[i],
            1,
            &written,
            NULL
        );

        Sleep(delayMs);
    }
}

int main() {
    typewriterChinese(L"你拿起那颗星星。", 100);
    return 0;
}

Visual Studio 项目继续保留：

  /utf-8

编译选项。


============================================================
【十三、暂时不要加入 emoji】
============================================================

先测试纯中文：

  L"你拿起那颗星星。"

暂时不要测试：

  L"⭐ 你拿起那颗星星。"

原因：

某些 emoji 在 Windows UTF-16 宽字符表示中可能由两个 wchar_t 组成。
如果每次只输出一个 wchar_t，仍可能把 emoji 拆开。

正确学习顺序：

  1. 先让纯中文逐字输出成功；
  2. 再处理标点和换行；
  3. 最后单独处理 emoji。

【十四、当前必须理解的内容】
============================================================

必须理解：

  wchar_t          宽字符类型
  L"中文"          宽字符串
  WriteConsoleW    向 Windows 控制台输出宽字符
  &text[i]         当前字符的地址
  Sleep            每个字之间暂停

暂时不需要理解：

  UTF-8 每个字节的二进制结构
  位运算掩码
  代理对的底层编码原理
  Windows Unicode 的全部历史


============================================================
【十五、一句话记住】
============================================================

英文打字机：

  char* + printf("%c") + fflush(stdout)

中文打字机（当前 Windows 方案）：

  wchar_t* + L"中文" + WriteConsoleW + Sleep

当前目标：

  先把纯中文完整地一个字一个字显示出来，不学位运算。
