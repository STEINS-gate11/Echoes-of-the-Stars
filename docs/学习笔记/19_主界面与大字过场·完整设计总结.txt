【二、《星空回响》完整叙事流程】
============================================================

从游戏启动到玩家进场景，一共 5 层引导：

  运行游戏
    ↓
  ① show_title()           主界面 · 星带呼吸
    按空格 ↓
  ② show_big_title()       大字过场 · "星    空    回    响" 逐字浮现
    按空格 ↓
  ③ get_to_the_hall()      加载 hall + 画 6 个门
    内部先播 play_the_pangbai(0)  ← 开篇散文 8 页
    ↓
  玩家在 hall 走到章 1 门口，按 E
    ↓
  ④ play_pangpai(1)        章节过场 · "序 幕 · 深 夜"
    按空格 ↓
  ⑤ play_the_pangbai(1)    幕间散文 · 6 页
    按 Enter ↓
  ⑥ load_secene(prologue)  进入序幕书房场景

每一层的作用：
  ① 主界面 —— 邀请玩家进入
  ② 大字过场 —— 建立仪式感
  ③ 开篇散文 —— 立起主角、织女星、三件物品的语境
  ④ 章节过场 —— 骨架（一句话本章讲什么）
  ⑤ 幕间散文 —— 血肉（长篇散文 + 画面高亮）

【五、五大设计原则】
============================================================

★ 数据驱动（Data-Driven）
   加新章、改颜色、改墙、改文案 —— 只改数据表，不改代码逻辑

★ 单一数据源（Single Source of Truth）
   拾取状态：链表是唯一权威
   进场景时 flag 从链表推算（have_already_pick）

★ 关注点分离（Separation of Concerns）
   load_secene 只管加载 + 绘背景
   checkwall 只管判墙
   playconversation 只管播对话
   insert_tail 只管入链表

★ 显示层与数据层同步
   屏幕字符 = bg[][] 里的记录
   拾取物品两层同时改

★ 一次性触发（Once-Only Trigger）
   幕间散文只在第一次进场景播
   章节过场也是（同一个 pangbai_alredy[] flag）

【六、视觉设计原则】
============================================================

▌ 织女星 ✦ = 她的化身
   全篇位置从不变
   只有亮度在变
   医院段（章 4）唯一一次暗掉 —— 因为主角刻意不抬头
   天文馆段（章 5）重新亮起 —— 他回来了

▌ 桌面三件物品 = 记忆的锚点
   ⭐ 折纸星星 → 从"不知谁折的"到"她折的"
   📖 空白日记本 → 从"未写过"到"第一行"
   🖼 模糊照片 → 从"看不清"到"认出来是我们"

▌ 从暖到冷再回到暖
   序幕（暖）→ 图书馆（温）→ 天台（明）
   → 医院（冷 · 唯一织女星暗）
   → 天文馆（沉）→ 回响（暖）

【八、本笔记涉及的新技术点】
============================================================

▌ 非阻塞按键 _kbhit()
   传统 _getch() 是阻塞的（等玩家按键才继续）
   _kbhit() 检查是否有按键，没有立即返回 0
   配合 Sleep 循环可以做"边动画边等按键"

   代码模式：
     for (int i = 0; i < 10; i++) {
         if (_kbhit()) {
             char c = _getch();
             if (c == ' ') return;
         }
         Sleep(50);
     }

▌ 循环取余做动画
   colors[5] + round % 5 → 无限 5 帧循环
   colors[3] + round % 3 → 无限 3 帧循环
   colors 数组决定"关键帧"，% 决定"多少帧循环"

▌ 顺序动画（不用主循环）
   一次性动画（比如"字浮现"）：
     setColor(14); gotoxy(x,y); printemoji(ch); Sleep(400);
     setColor(6);  gotoxy(x,y); printemoji(ch); Sleep(200);
     setColor(14); gotoxy(x,y); printemoji(ch); Sleep(200);
   顺序执行，Sleep 决定节奏，不需要"主循环"

▌ 持续动画（用主循环）
   循环状态的动画（比如"星带呼吸"）：
     while (1) {
         setColor(colors[round % 5]);
         printemoji(...);
         round++;
         // 中间用 _kbhit 检查按键，退出循环
     }

【九、一句话答辩总结】
============================================================

"这是一个 C 语言写的控制台交互叙事游戏。
 6 章 15 件物品，双向链表存对话历史，
 数据驱动的墙表和颜色表，
 单一数据源保证拾取状态跨场景一致。
 开场有星带呼吸的主界面 + 大字过场，
 7 段带画面高亮的幕间散文串联全部剧情。"

【技术亮点】
   · 双向链表 + malloc/free 内存管理
   · 数据驱动配置（数组化的墙/颜色/对话/幕间表）
   · 全局状态机（cur_chapter 决定所有查表）
   · 显示/数据分离，逐字符渲染 + 章节颜色查表
   · 一次性触发的叙事系统（pangbai_alredy[7]）
   · 5 帧平滑呼吸动画（colors[5] + % 5 循环）
   · 打字机 + 逐字符高亮的组合效果
   · 非阻塞按键 + 顺序动画 + 主循环动画三种时序
