============================================================
《星空回响》BGM 策划表 · v1（整理版）
============================================================

【说明】
- 全部曲目来自现有 galgame（Summer Pockets / Anemoi 等）
- 实际使用时需要放 .wav 或 .mp3 到 res/bgm/ 目录
- 用 Windows API `mciSendString` 或 `PlaySound` 循环播放
- 每次场景切换用淡入淡出（500-1000 ms）过渡


============================================================
【一、标题界面】
============================================================

  BGM        : Summer Pockets 开场 bgm
  文件名建议 : title.mp3
  播放方式   : 循环
  淡入       : 从静音 → 100%（用 3 秒）
  何时切换   : 玩家按空格进入序幕
  情绪       : 温柔、召唤、有点熟悉的邀请感

  幕                          BGM                                情绪
  --------------------------  ---------------------------------  -----------
  幕 0 · 引言（全黑）          将幸福装满口袋                     开场
  幕 1 · 宇宙①（天文馆）       将幸福装满口袋                     美好的可能
  幕 2 · 宇宙②（医院）         将幸福装满口袋                     弥补的可能
  幕 3 · 宇宙③（分屏）         将幸福装满口袋                     各自的可能
  幕 4 · 这个宇宙（书房）       将幸福装满口袋                     我们的实际结局
  幕 5 · 她说（浅紫）           将幸福装满口袋                     独白
  幕 6 · 献词                   将幸福装满口袋                     真正的收束

  ★ 全程一首歌，不切歌 —— 这是 TE 最强的音乐设计 ★

  播放规则：
  - TE 开始时"将幸福装满口袋"从头淡入（3000 ms）
  - 全程 6 幕不切歌、不淡出，只用画面变化推进
  - 玩家会感觉整个 TE 是"一首歌的时间"
  - 幕 5 "她说" 部分可以把音量稍稍降低到 60%
    让她的字幕更清晰
  - 幕 6 献词后音乐随画面渐暗一起淡出（5000 ms）
  - 回标题时音乐才停止

  为什么这样设计：
  - "将幸福装满口袋" 是 Summer Pockets 的 ED
    是一首完整的歌 —— 前奏 / 主歌 / 副歌 / 尾奏
  - TE 全 6 幕约 90 秒，正好一首歌能覆盖完
  - 玩家听到"这首歌前奏响起就意味着 TE 开始了"
    结束时"最后一个音符落下就是游戏结束"
  - 一首歌 = 一个完整的告别

【六、总体播放技术建议】
============================================================

  推荐用 Windows Multimedia API：

  #include <windows.h>
  // 加库：#pragma comment(lib, "winmm.lib")

  // 播放
  mciSendString("open \"res/bgm/title.mp3\" alias bgm", NULL, 0, NULL);
  mciSendString("play bgm repeat", NULL, 0, NULL);

  // 停止 + 释放
  mciSendString("stop bgm", NULL, 0, NULL);
  mciSendString("close bgm", NULL, 0, NULL);

  // 音量（0-1000）
  mciSendString("setaudio bgm volume to 500", NULL, 0, NULL);

  淡入淡出：用 timer 每 50 ms 调 setaudio 提升/降低 volume。
