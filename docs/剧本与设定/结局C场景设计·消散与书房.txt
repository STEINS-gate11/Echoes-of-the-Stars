【设计时间】2026-07-30

【设计原则】
============================================================

▌ C 是最狠的
   A 是抵达 · B 是无奈 · C 是遗忘
   主角连自己是谁都记不清了
   连"她"这个字都是空的
   连"愿望"这个词都不知道什么意思

▌ 视觉核心 · 三层暗
   第一层 · 消散动画屏(段 0)· 全屏黑 · 物品逐个消散
   第二层 · 书房 mode=2 暗色 · 台灯还亮但环境暗如深海
   第三层 · 段 7 淡出 · 一层一层暗 · 主角最后失

▌ C 独有的三个视觉元素
   · 消散动画屏(段 0)· 独立场景 · 不是书房
   · 镜子(段 1)· 左上角小镜子 · 里面从 ? 变 @
   · 高亮"她"字(段 5)· 慢慢变灰

▌ 玩家选择的 4 个细节(2026-07-30 确定)
   1. 段 0 消散 · 屏幕中心 · 逐个交替(不是列表)
   2. 段 1 镜子 · 左上角小镜子
   3. 段 5 "她"字 · 高亮后慢慢变灰
   4. 段 7 淡出 · 一层一层暗 · 主角最后失

【C 段落动画流程】
============================================================

段 0 · 消散动画(约 50 秒)
─────────────────────────────
  · 屏幕全黑
  · 依次播 15 件物品的消散
  · 播完后 · 一秒静默
  · 淡入书房场景

段 1 · 回到桌前 · 认不出自己(约 75 秒)
─────────────────────────────
  · 淡入书房 · mode=2 · 极暗
  · 台灯 · @ · 桌上三物件 · 镜子 · 依次出现
  · 主角 @ 在 (26, 14) · 静止
  · 镜子里 · x=4 y=8 是 ?
  · 独白播「你回到桌前。台灯亮着...」
  · 独白播到「你抬头看向了对面的墙」时:
      镜子里的 ? 高亮 500ms(白 15) · 说明"里面有人"
  · 独白播「那个人看着你,你也看着他」
  · 停 3 秒
  · 镜子里的 ? · 逐字符变化:
      x=4 y=8 · ? → 空 · 停 200ms
      x=4 y=8 · 空 → @ · 白 15
  · 独白播「你花了大概三秒钟,才想起来 —— 那个人是你」
  · 按空格继续

段 2 · 折纸星星 · 读到字 · 笑了(约 75 秒)
─────────────────────────────
  · @ 保持不动
  · 独白播「你伸手把那颗折纸星星拿了起来...」
  · x=23 y=11 · ⭐ · 缓慢变化(和 B 一样):
      ⭐ → ✧ → ─
  · 独白播「里面写着一行字:'如果你看到这个,说明你已经准备好了'」
  · 独白播「你笑了」
      —— 这里可以让 @ 短暂闪一下(色 15 → 14 → 15)· 500ms
  · 独白播完 · 按空格继续
  · 展开的纸 · 折回去(─ → ⭐)· 静止

段 3 · 日记本 · 擦掉的字(约 70 秒)
─────────────────────────────
  · @ 保持不动
  · 独白播「桌上还有一本日记本...」
  · 独白播「第一页的顶上,有一行淡淡的痕迹」
  · x=29 y=11 附近 · 短暂显示一行"─────"(灰 8)· 停 500ms
      —— 表示"曾经写过字"
  · 那一行 · 变成空白 · 消失
  · 独白播「不是字。是有过字、可是被人擦掉之后剩下的、铅笔的印子」
  · 独白播完 · 按空格继续

段 4 · 照片 · 自己身上就是那个味道(约 90 秒 · 最重)
─────────────────────────────
  · @ 保持不动
  · 独白播「桌上还有一张模糊的照片...」
  · 独白播到「披着藏青色的外套」时:
      x=35 y=11 · 🖼 高亮一下(白 15) · 500ms
      然后变回暗 8
  · 独白播「你低下头,看你自己身上穿的那件外套」
      —— 这里可以让 @ 从 (26, 14) 变成 ◉(俯身自看)· 500ms
      —— 然后变回 @
  · 独白播「你的心脏,今夜第一次,跳了一下」
      —— 这里让台灯闪一下(色 7 → 15 → 7)· 300ms
      —— 主角 @ 也闪一下 · 表达"心脏跳了一下"
  · 独白播完 · 按空格继续

段 5 · 抬头 · "她"这个字是空的(约 80 秒)
─────────────────────────────
  · 独白播「你站起来,走到窗前」(和 B 一样 · @ 其实不动)
  · 独白播「你抬起头。有一颗星,比其他所有星都要亮」
  · 织女星 ✦ · 从极暗 1 · 慢慢变亮到灰 8 · 停 3 秒
      —— 表示主角"看见了"这颗星
  · 独白播「从她那里出发的」
  · 高亮特效 —— 独白区里的"她"字:
      · 打字机打到"她"字时 · 用白 15 显示(其他字用灰 7)
      · "她"字停在屏幕上 1 秒 · 高亮持续
      · 然后"她"字慢慢变灰(15 → 7 → 8 · 每档 500ms)
      · 变成和其他字一样的灰 7 · 融入
  · 独白播「你脑子里冒出了'她'这个字」
  · 独白播「你脑子里的'她'这个字,是空的」
  · 独白播完 · 按空格继续

段 6 · 空 · 连"想哭"都不确定(约 65 秒)
─────────────────────────────
  · 织女星 ✦ · 慢慢变回极暗 1
  · 主角 @ · 保持在 (26, 14)
  · 独白播「你在窗前站着,站了很久」
  · 独白播「眼眶还是热的。可是眼泪没有掉下来」
  · 独白播「你甚至不确定,你今夜的这个'想哭'本身,是真的想哭...」
  · 独白播完 · 按空格继续

段 7 · 收尾 · 连"愿望"是什么都不记得(约 30 秒)

  · 独白播「窗外一颗流星划过」
  · 屏幕右上 · 一颗流星从 (48, 2) 划到 (30, 5)
      · 每格 100ms · 用 * 或 · 表示
      · 划完消失(不留痕)
  · 独白播「你没有许愿」
  · 独白播「因为你不记得,你曾经想向谁许愿」
  · 独白播「你甚至不记得,'愿望'这个词,是什么意思」

  · 一层一层暗 · 主角最后失:

▌ 消散动画(段 0)
   void play_dissipation_animation(void) {
       const wchar_t* items[15] = {
           L"⭐ 折纸星星", L"📖 空白日记本", L"🖼 模糊照片",
           L"📚 天文书籍", L"☕ 两杯咖啡", L"📝 手写便签",
           L"🔭 望远镜",   L"📸 拍立得照片", L"🎵 耳机",
           L"📋 检查报告", L"📱 手机屏幕",   L"💊 未开封的药",
           L"🎫 两张门票", L"💌 没寄出的信", L"⭐ 拆开的星星"
       };
       system("cls");
       for (int i = 0; i < 15; i++) {
           int len = (int)wcslen(items[i]);
           int x = (50 - len * 2) / 2;   // 居中
           int y = 12;

           // 显示物品
           gotoxy(x, y); setColor(6); printWideAll(items[i]);
           Sleep(1500);

           // 字符逐个变 ·
           for (int j = 0; j < len; j++) {
               gotoxy(x + j * 2, y); setColor(8); printWideAll(L"·");
               Sleep(150);
           }
           Sleep(500);

           // 空格擦除
           gotoxy(x, y);
           for (int j = 0; j < len * 2; j++) printf(" ");
           Sleep(500);
       }
       Sleep(1000);   // 一秒静默
   }

▌ 一层一层暗(段 7)
   void fade_out_C(void) {
       // 步骤 1 · 背景星星消失
       for (int y = 0; y <= 4; y++)
           for (int x = 0; x < 30; x++) {
               gotoxy(x, y); printf(" ");
           }
       Sleep(500);
       // 步骤 2 · 织女星消失
       gotoxy(34, 1); printf(" ");
       Sleep(500);
       // 步骤 3 · 便利店灯消失
       gotoxy(37, 4); printf(" ");
       Sleep(500);
       // ... 其余步骤依此类推
       // 步骤 9 · 主角 @ 分三档暗:
       gotoxy(26, 14); setColor(8); printf("@"); Sleep(800);
       gotoxy(26, 14); setColor(1); printf("@"); Sleep(800);
       gotoxy(26, 14); printf(" ");
       Sleep(5000);   // 全黑停 5 秒
   }
