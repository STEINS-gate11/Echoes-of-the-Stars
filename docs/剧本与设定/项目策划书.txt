## 一、项目概述

### 1.1 一句话介绍
> 一个通过探索记忆碎片、拼凑故事的交互叙事游戏。玩家在控制台操作光标，在5层记忆场景中寻找物品，解锁一段关于星空、约定与告别的完整故事。

### 1.2 核心玩法
- 玩家用 **WASD** 在场景中移动光标
- 按 **E** 与物品交互，触发对话
- 每层找齐所有物品 → 自动进入下一层
- 找齐全部15个物品 → 解锁"真结局"
- 按 **B** 回看对话历史（栈）
- 按 **C** 查看已收集物品清单（链表）

### 1.3 核心卖点
| 卖点 | 说明 |
|------|------|
| 有故事 | 五层记忆+双结局，情感驱动 |
| 有交互 | 不是纯播放器，玩家主动探索 |
| 有视觉 | 彩色字符画+动态星空 |
| 有数据 | 栈+链表两个数据结构落地 |
| 有差异 | 全班唯一一个叙事类项目 |


## 二、技术方案

### 2.1 技术栈
| 技术 | 用途 |
|------|------|
| C++ | 主语言（类+继承+vector+string） |
| Windows API | 控制台光标控制（gotoxy） |
| conio.h | 键盘监听（_getch） |
| 标准库 | 输入输出、字符串、容器 |

### 2.2 核心数据结构
| 数据结构 | 用途 | 体现在哪 |
|---------|------|---------|
| **栈** | 对话历史回退 | 玩家按B键回看上一条对话 |
| **链表** | 已收集物品清单 | 玩家按C键查看全部收集进度 |
| 结构体数组 | 每层的背景画 | 20行×48列字符画 |
| vector | 每层的物品列表 | 动态管理物品数量 |

### 2.3 架构设计（三层结构）
```
┌─────────────────────────────────────────────┐
│  表现层：控制台输出（彩色+光标+动画）        │
├─────────────────────────────────────────────┤
│  逻辑层：场景切换/交互判定/剧情推进          │
├─────────────────────────────────────────────┤
│  数据层：5层场景/15个物品/对话文本/结局条件   │
└─────────────────────────────────────────────┘
```

### 5.2 背景图设计指南

**原则**：
- 每个字符占一个格子，用等宽字体（Consolas）
- 边框用 `┌ ┐ └ ┘ │ ─`
- 物品用emoji（⭐ 📖 🖼️ 等）
- 星星用 `★` 或 `✦`
- 空位用空格填充
- 每行长度必须一致（48个字符宽）

**参考模板**（序幕）：
```
第00行："                              ★               "
第01行："          ★                                  "
第02行："  ┌───────────────────────────────────────┐  "
第03行："  │                                       │  "
第04行："  │       ⭐          📖                  │  "
第05行："  │                                       │  "
第06行："  │                 🖼️                    │  "
第07行："  │                                       │  "
第08行："  │    深夜书房，桌上放着三样东西        │  "
第09行："  │    你不记得它们来自哪里              │  "
第10行：" │                                       │  "
第11行：" └───────────────────────────────────────┘  "
第12行："             ★                             "
第13行："         ★                                 "
第14~19行："                                        "
```
