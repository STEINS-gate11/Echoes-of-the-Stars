============================================================
《星空回响》章节过场模板
============================================================

【使用时机】
- 主线：玩家满足条件（本层 3 物品拾取完）后按 Enter，
        触发过场 → 进入下一层
- Vega 线：每个场景切换时（章节名换成地点名）
- TE 线：幕间转场（不显编号，只显引导词）
- 全项目只需要一个通用过场函数，参数化即可

二、6 章内容表（主线）
============================================================

  ============================================================
   触发时机           编号       章节名     层间旁白
  ============================================================
   游戏开始 → 序幕    序   幕    深    夜   （无。直接播章节名进书房）
  ------------------------------------------------------------
   序幕   → 第 1 层   第 一 章   初    遇   你不记得她是谁了。
                                            但你还记得，你答应过她要去看星星。
  ------------------------------------------------------------
   第 1   → 第 2 层   第 二 章   相    伴   后来你们真的去看了很多次星星。
                                            那时候你以为，这只是个开始。
  ------------------------------------------------------------
   第 2   → 第 3 层   第 三 章   裂    缝   然后有一天，你发现星星也会消失。
                                            你只是没想到，这一次会轮到她。
  ------------------------------------------------------------
   第 3   → 第 4 层   第 四 章   缺    席   她没有怪你。
                                            但你怪了自己很久。
  ------------------------------------------------------------
   第 4   → 第 5 层   第 五 章   回    响   你终于准备好了。
  ============================================================

  说明：
  - "序幕"是唯一没有前置旁白的章（游戏开场）
  - "回响"的旁白只有一句（原叙事总表就是一句）
  - 编号里"第 一 章"三个字之间用 1 空格分隔，视觉上更庄重

三、渲染时序（每一步的时长）
============================================================

  步  动作                                         时长
  --  --------------------------------------------  ------
  1   全屏清成黑底                                  0 ms
  2   停顿                                          500 ms
  3   上装饰线 ═══ 渐入（灰 8 → 白 15，5 步）        200 ms
  4   编号"第 X 章"逐字出现（每字 100 ms）           400 ms
  5   停顿                                          400 ms
  6   章节名逐字出现（每字 200 ms，慢一档）         800 ms
  7   停顿                                          500 ms
  8   下装饰线 ═══ 渐入                              200 ms
  9   停顿                                          800 ms
  10  旁白第 1 行打字机（40 ms/字）                 ~800 ms
  11  停顿                                          300 ms
  12  旁白第 2 行打字机（如有）                     ~800 ms
  13  停顿                                          1000 ms
  14  装饰点线 · · · · · 出现                        200 ms
  15  按空格提示出现（缓慢闪烁 800 ms 周期）        500 ms
  16  等 SPACE                                     阻塞
  17  全屏渐出（15 → 8 → 0，4 步）                  400 ms
  18  切换到下一场景                                0 ms

  总时长（不含玩家等待）：约 7.5 秒

  说明：不做"快进"。每一步都必须完整播出。玩家的 SPACE
       只在步骤 16 才响应。


============================================================
四、Vega 线的变体
============================================================

  4 个场景切换时用同一模板，把"编号 / 章节名"换成：

    ═══════════════════════════════════════

               PERSPECTIVE : VEGA

                   图  书  馆

    ═══════════════════════════════════════

  Vega 的 4 个地点：
    图  书  馆
    天       台
    医  院  走  廊
    她  的  房  间

  ★ "PERSPECTIVE : VEGA" 用浅紫色（13）
  ★ 地点名用白色（15）
  ★ 旁白（如有）也用浅紫，因为是 Vega 视角


============================================================
五、TE 幕间的变体
============================================================

  不显示章节名，只显示引导词，格式简化：

    ═══════════════════════════════════════

              在 另 一 个 宇 宙 里 ——

    ═══════════════════════════════════════

    （无长旁白）

    [ 按空格继续 ]

  ★ 3 个宇宙的引导词分别是：
      幕 0 → 幕 1 :  在 无 数 个 宇 宙 里 ——
      幕 1 → 幕 2 :  在 另 一 个 宇 宙 里 ——
      幕 2 → 幕 3 :  还 有 一 个 宇 宙 里 ——
      幕 3 → 幕 4 :  …… 但 在 这 个 宇 宙 里 ，
      幕 4 → 幕 5 :  （不用过场，直接淡入她说画面）
      幕 5 → 幕 6 :  （不用过场，直接淡入献词）

// 通用过场函数
void playTransition(
    const char *label,       // "序   幕" / "第 一 章" / "PERSPECTIVE : VEGA" / NULL
    const char *sceneName,   // "深    夜" / "初    遇" / "图  书  馆" / 引导词
    const char *line1,       // 旁白第 1 行，可为 NULL
    const char *line2,       // 旁白第 2 行，可为 NULL
    int labelColor,          // 15 白 / 13 浅紫
    int nameColor            // 同上
);

// 主线数据表
struct Chapter {
    const char *label;
    const char *name;
    const char *narrLine1;
    const char *narrLine2;
    int  labelColor;
};

Chapter mainlineChapters[6] = {
    {"序   幕", "深    夜", NULL, NULL, 15},
    {"第 一 章", "初    遇",
     "你不记得她是谁了。",
     "但你还记得，你答应过她要去看星星。", 15},
    {"第 二 章", "相    伴",
     "后来你们真的去看了很多次星星。",
     "那时候你以为，这只是个开始。", 15},
    {"第 三 章", "裂    缝",
     "然后有一天，你发现星星也会消失。",
     "你只是没想到，这一次会轮到她。", 15},
    {"第 四 章", "缺    席",
     "她没有怪你。",
     "但你怪了自己很久。", 15},
    {"第 五 章", "回    响",
     "你终于准备好了。", NULL, 15},
};

// 触发
void enterChapter(int i) {
    Chapter *c = &mainlineChapters[i];
    playTransition(c->label, c->name, c->narrLine1, c->narrLine2,
                   c->labelColor, 15);
    loadScene(sceneFileOf(i));
}
