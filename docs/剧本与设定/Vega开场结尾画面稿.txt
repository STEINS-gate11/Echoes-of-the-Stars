============================================================
《星空回响》Vega 开场 + 结尾画面稿
============================================================

【本文件包含】
- Vega Line 开场：从标题界面进入 → 淡入引言 → 转入图书馆
- Vega Line 结尾：场景 4 结束后 → 收尾字幕 → 回标题

【触发条件】
- 开场：玩家在标题界面选 [V] Vega Line
        （条件：mainlineACleared / B / C 任一 == true）
- 结尾：vega_room.txt 场景 4 T4 触发完成 → 场景收尾独白播完

【重要排版原则】
- 含中文的文字框：只画"上下横线"，不画左右竖线
- 中文/★ 都不受右边界约束
- 运行时由代码用 gotoxy 精确定位显示

【关键呼应设计】

  "我一直都在" 这五个字：
    - 主线 A 结局 · 她说 : "别再回头找我了 —— 我一直都在。"
    - Vega 结尾           : "我一直都在。"

    同一句话说两次。
    第一次是远远地喊。第二次是贴着耳朵说。


  "我很喜欢你" 这四个字：
    - Vega 场景 1 · T1 (图书馆放书处):
      "翻到扉页，用铅笔写了一行字。"
      "'你也喜欢星星吗？'"

    5 年前，她没敢直接说，用"你也喜欢星星吗"代替。
    5 年后，她终于说了。

    "从图书馆那本书开始" —— 玩家会突然反应过来：
    那本书上的一行字，就是她当年的告白。


  "我想成为你的牛郎星" (主线 A · 主角) :
  "ps: 希望做你的织女星" (主线 A · 她说) :
  "我很喜欢你"           (Vega 结尾)     :

    三层告白，一个比一个直接。
    最后一层最直白，却是这个故事最动人的一句。

    主线 A · 主角 : "我想成为你的牛郎星。"

    Vega 结尾    : "我很喜欢你。"

【实现建议】

// 通用签名浮字
void driftInSignature(int x, int y,
                      const char *text, int color, int fadeMs);

// 画上下横线（不画竖线）
void drawTopBottomLines(int x, int yTop, int yBottom,
                        int width, int color);

// Vega 开场
void playVegaOpening() {
    fadeOut(400);
    Sleep(500);
    drawPerspectiveTag(0, 0, "PERSPECTIVE : VEGA", 13);
    drawStarField(vegaOpeningStars, 400);   // 星点
    drawTopBottomLines(8, 5, 16, 40, 13);   // 上下横线，无竖线
    playText(vegaOpeningSegments, 4, 40);   // 4 段打字机
    driftInSignature(60, 18, "-- Vega", 5, 400);
    Sleep(3000);
    waitSpace();
    fadeOut(400);
    Sleep(500);
    // 进入 vega_library.txt
}

// Vega 结尾
void playVegaEnding() {
    // 幕 D：室内对话框（自动）
    playDialog(&vegaRoomOutro1);
    playDialog(&vegaRoomOutro2);
    fadeOut(400);

    // 幕 E：结尾字幕
    drawStarField(vegaEndingStars, 400);
    drawTopBottomLines(8, 4, 17, 40, 13);
    playText(vegaEndingSegments, 4, 40);
    driftInSignature(60, 19, "-- Vega", 5, 400);
    Sleep(5000);
    waitSpace();

    // 幕 F：回标题
    fadeOut(600);
    Sleep(2000);
    save.vegaCleared = true;
    saveGame();
    goToTitle();
}
