【全局规则】

- 场景文件严格纯 ASCII（title.txt 特殊，允许中文，用"上下横线"版式）

- 碰撞集：+ - | = ( ) _ [ ] # / \ '
- 可穿透装饰：空格 . * ~ '  （但 ~ 作栏杆时视为碰撞）

【实现要点】
========================================

1. 场景加载：
   char bg[20][49];
   FILE *fp = fopen("res/prologue.txt", "r");
   for (int y = 0; y < 20; y++) {
       fgets(bg[y], 49, fp);
       int len = strlen(bg[y]);
       if (len > 0 && bg[y][len-1] == '\n') bg[y][len-1] = '\0';
   }
   fclose(fp);

2. 碰撞检测：
   bool blocked(char c) {
       return strchr("+-|=()_[]#/\\'", c) != NULL;
   }

3. 物品渲染（在场景骨架之上叠加）：
   for (int i = 0; i < 3; i++) {
       Item *it = &items[i];
       if (it->taken) continue;
       gotoxy(it->x, it->y);
       if (it->hidden && !it->discovered) {
           setColor(4);  // 深红
           printf("?");
       } else {
           setColor(14); // 金色
           printf(it->displayChar);
       }
   }


========================================
【场景文件行数硬约束】
========================================
所有场景 .txt 必须严格 20 行。
超行会导致：
- fgets 循环读入越界数据
- 场景底部意外多出一行边框
- 玩家看不到最下方设计的地板 / 边界字符


========================================
【场景文件 ASCII 硬约束】
========================================
除 title.txt 外，所有场景 .txt 必须 100% 纯 ASCII (char 32-126 + '\n')。
禁止在场景 txt 里放：
- 中文（会导致 VSCode / 编辑器渲染不齐）
- emoji (⭐ 📖 🖼 等)
- ★ / ✦ / ┌ ┐ / ╔ ╝ 等全宽或 Unicode box 字符

正确做法：
- 场景 txt 只画 "骨架"（ASCII 边框 / 家具 / 星点 * . '）
- 中文标题、emoji 物品、Unicode 星星，全部在代码里
  用 gotoxy + printf 叠加到骨架上

title.txt 特殊：允许中文，用"上下横线，无左右竖线"版式。

验证：cd 到项目目录 → python check_align.py
