《星空回响》章节过场设计
============================================================

【设计时间】2026-07-30
【适用】结局触发时的转场 + 结局内部场景切换 + 结局→献词→主菜单

【玩家选择】(2026-07-30 确定)
  1. hall → 结局开场:淡出 + 字幕 + 淡入(推荐)
  2. A 结局内部场景切换:直接切 · 无淡出
  3. A 结局内部字幕:时间 + 地点 · 两行
  4. 结局播完 → 献词 → 结束:黑屏 + 献词 + 按键回主菜单

【二、hall → 结局 A/B 开场 · 淡出+字幕+淡入】
============================================================

▌ 分 3 阶段 · 共 6 秒

  阶段 1 · hall 淡出(2 秒)
    从上到下 · 一层一层擦
    步骤 A · 顶部星轨(y=0..2)· 星星逐个变空格 · 500ms
    步骤 B · 顶部围墙 ==(y=3)· 变空格 · 300ms
    步骤 C · 中央 ✦ 和"—— 终章 ——"· 变空格 · 300ms
    步骤 D · 6 扇门 D · 变空格 · 500ms
    步骤 E · 下边框 · 变空格 · 400ms
    最后:全屏黑

  阶段 2 · 黑屏字幕(2 秒)
    system("cls") 已经全黑
    在屏幕中央显示两行字:
      第 1 行 · x = 居中  y = 11  · 时间
      第 2 行 · x = 居中  y = 13  · 地点
    颜色:白 15
    停 2 秒

  阶段 3 · 淡入书房(2 秒)
    先擦掉字幕(y=11, 13 的两行)
    然后画书房的元素 · 从外到内 · 一层一层出现
    步骤 A · 顶部星星 · 300ms
    步骤 B · 书房外墙 · 300ms
    步骤 C · 书桌 · 书架 · 400ms
    步骤 D · 桌上三物件 · 400ms
    步骤 E · 主角 @ · 300ms
    然后进入段 1 · 独白

▌ 结局 A 开场字幕
   第 1 行 · "—— 今夜 ——"
   第 2 行 · "书房"

▌ 结局 B 开场字幕
   第 1 行 · "—— 今夜 ——"
   第 2 行 · "书房 · 台灯还亮着"

▌ 为什么不写"第 X 章"
   已经过了 6 章 · 玩家知道自己在 finale
   这里的字幕是"进入结局"的仪式感 · 不是章节标题

【九、献词 → 主菜单过渡】
============================================================

▌ 献词播完后

  阶段 1 · 献词播完 · 底部显示"[ 按 空 格 继 续 ]"
  阶段 2 · 玩家按空格

  阶段 5 · 调用 begin_title() · 回主界面
    · begin_title() 已存在 · 会重新初始化主菜单

▌ 关键点
   · 记忆值 memory_zhi 需要在 begin_title() 里被 reset_memory() 重置
   · pangbai_alredy 数组也需要重置(允许玩家再玩一次)
   · total_size · head · tail · 双向链表需要清空
   · game_begin_locked 数组重置

▌ 重置函数原型

  void reset_all_game_state(void) {
      // 记忆值
      memory_zhi = 100;
      time_top = 0;
      memory_last = 0;

      // 章节旁白
      for (int i = 0; i < 7; i++) pangbai_alredy[i] = 0;

      // 章节锁
      for (int i = 0; i < 7; i++) game_begin_locked[i] = 0;
      game_begin_locked[1] = 1;   // 只解锁第一章

      // 双向链表
      conver_node* p = head;
      while (p) {
          conver_node* next = p->next;
          free(p);
          p = next;
      }
      head = tail = NULL;
      total_size = 0;
  }

【十二、设计备注】
============================================================

▌ 淡出淡入只用在 hall → 结局开场
   仪式感 —— 玩家值得一个"进入结局"的过渡

▌ A 结局内部切场景 · 直接切
   减少玩家等待时间(A 已经很长)
   字幕 2 秒足够表达"时空跳跃"

▌ B 和 C 的黑屏比 A 长
   A 停 1 秒(温暖 · 释怀)
   B 停 3 秒(无奈 · 需要更长的沉默)
   C 停 5 秒(遗忘 · 让玩家在这个"什么都没有"里坐一会儿)

▌ 字幕不用打字机
   打字机太"有存在感"· 字幕的意图是"低声告知"
   一次性显示 · 停 2 秒 · 就够

▌ 主循环 break 前要保证 begin_title 可以正常调
   避免变量在中间状态 · 用 reset_all_game_state() 完全重置
