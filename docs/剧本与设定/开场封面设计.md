# 《星空回响》开场封面设计

> 依据：控制台版 `begin_title()`（源.cpp 262–386）+ `title.txt`。
> 原则：控制台标题屏里已经有的元素，一个都不丢；控制台做不到的（真实图像、渐变、音乐淡入），才是引擎版要加的。

## 二、五句寄语（每次启动随机一句）

源码 302–308，`time(NULL) % 5`：

1. 如果你看到这个，说明你已经准备好了。
2. 星光走了 25 年，才到你眼睛里。
3. 有些星星，在夜空里，也在你记得的地方。
4. 她答应过你——星星还会在这里。
5. 一颗折了又拆的纸星星。

> 这五句是**剧透与不剧透的边界**。第 1 句是星星里的字，第 4 句是她的承诺，第 2 句是全篇的核。第一次玩的人看不懂，通关之后再回标题屏，五句全都变成了另一个意思。
> **所以必须随机，不能固定一句。** 玩家反复回到标题屏才会集齐五句。

## 三、封面构图

```
┌──────────────────────────────────────────────┐
│  ·   .        ✦                    . ✦ .     │ ← 星空，呼吸式明暗
│        流星 ↘                         .      │ ← 流星偶发，右上→左下
│ ──────────────────────────────────────────── │ ← 上边框（原 +====+）
│                                              │
│              ★  星空回响  ★                  │ ← 暖黄，发光
│            Echoes of the Stars               │ ← 暗一档
│                                              │
│      一个关于星星、约定和告别的故事           │
│                                              │
│                 开始旅程                     │
│                 继续游戏                     │ ← 无存档时置灰
│                 回  廊                       │
│                 退  出                       │
│                                              │
│     「星光走了 25 年，才到你眼睛里。」        │ ← 五句随机一句
│                                              │
│ ──────────────────────────────────────────── │ ← 下边框
│      献给每一个曾经抬头看星星的人             │ ← 最暗
└──────────────────────────────────────────────┘
```

**背景图内容（1536×1024 横向）**：从旧天文台天台往上看的夜空。画面下缘压着一点点天台的实体——水泥栏杆的一角、以及右下角那台老望远镜的镜筒剪影（只出剪影，不出细节）。天空占画面 80%，星星密，其中西南方向一颗明显最亮。**不画人。**

> 为什么是天台不是书房：书房是「他忘记的地方」，天台是「她等他的地方」。封面应该是她的视角——她在这里等了三年。
> 为什么望远镜只出剪影：那封信藏在它底座下面。第一次看是背景道具，通关后再看就是全篇最重的东西。

## 四、生成提示词（横版 1536×1024）

> 按既定规矩：**风格声明放最前，摄影明确否定**。

```
日式 galgame 视觉小说的标题画面背景 CG，赛璐璐上色，清晰的色块与线条，
不是照片，不是写实摄影，不是 3D 渲染。

画面：夜晚，从一栋旧天文台的天台向上仰望的夜空。
天空占据画面上方五分之四，深靛蓝到近黑的渐变，布满大小不一的星点，
星点疏密不均，有几处聚成淡淡的银河带。
西南方向（画面偏右上）有一颗明显比其它星都亮的白色星星，
围绕它画出四道细长的十字光芒。

画面下缘：一道水泥栏杆的顶部，只露出很窄的一条，
深灰色，边缘有一点点风化的粗糙感。
画面右下角：一台老式反射望远镜的剪影，只有轮廓，
三脚架的一条腿微微歪斜，镜筒指向右上方的天空。
剪影内部用大面积暗色块简化处理，不画细节。

无人物。无文字。
色调：靛蓝、墨黑、冷白，只有那颗最亮的星是暖白色。
构图：画面正中和中上部留空，为标题文字留出位置。
```

**关键约束**：
- 中央必须留空 —— 标题、菜单、寄语都压在上面
- 无人物 —— 封面不能出现她，她要到 CG 1-B 才第一次露脸
- 无文字 —— 文字全部由引擎绘制，方便随机换寄语

## 五、动效（引擎版）

| 层 | 做法 |
|---|---|
| 背景图 | 静态，最底层 |
| 星空呼吸 | 一张星点图层，透明度 0.55 ↔ 1.0 循环，周期约 4 秒。对应源码 `color_total[5] = {8,7,6,7,8}` |
| 独立闪星 | 6 个小星点，各自错开相位闪。对应 `inner_stars[6]` 的 `diff` 值 0/2/1/3/4/2 |
| 织女星 | 常亮，四道十字光芒缓慢转 |
| 流星 | 从右上飞向左下，约 1 秒划完，之后随机停 5~15 秒再来一次。对应 `liu_xing_jishi = 10 + (xunhuannumber % 8)` |
| 标题淡入 | 进标题屏时，星空先亮 1 秒，标题再淡入 |
| BGM | 淡入，2 秒 |

## 六、主菜单（4 项）

```
                开始旅程
                继续游戏
                回  廊
                退  出
```

| 项 | 行为 | 对应控制台 |
|---|---|---|
| **开始旅程** | 从引言开始新游戏 | `begin_title()` 里的 `[空格]` |
| **继续游戏** | 读取存档，回到上次的层 | 控制台版没有，新增 |
| **回廊** | 已解锁 CG 鉴赏 | 控制台版 `begin_conver_history()` 的进化版 |
| **退出** | 退出 | `[Q]` |

### 关于「继续游戏」

- **没有存档时置灰**，不可点。不要弹「无存档」提示框——封面上弹窗很破气氛，灰掉就够了。
- 存档粒度按**层**存，不按句存：引言 / 序幕 / 第一~五章 / 结局A。跟 `pangbai_alredy[7]` 一个思路。

### 关于「回廊」

控制台版的 `begin_conver_history()`（源.cpp 1482）是用 A/D 键前后翻看已拾取物品的文字。引擎版升级成 CG 鉴赏，但**保留它那条最好的设定**：

> 源码 1486–1490：一件都没拾取时，显示「（还没拾取任何物品）」。

引擎版对应：**回廊初始是全空的**，一张都没有。每张 CG 只有在剧情里真正播放过一次，才会点亮。

`cg/` 目录现有 57 张，回廊按这个分组：

| 分组 | 文件 | 张数 |
|---|---|---|
| 引言 | `P-1` ~ `P-3` | 3 |
| 序幕 · 深夜书房 | `S-1` ~ `S-4` | 4 |
| 第一章 · 初遇 | `0.1cgA/B` `0.2cgA/B` `0.3cgA/B` | 6 |
| 第二章 · 相伴 | `1.*` | 6 |
| 第三章 · 裂缝 | `2.*` | 6 |
| 第四章 · 缺席 | `3.*` | 6 |
| 第五章 · 回响 | `4.*` `5.*` | 12 |
| 结局A | `A.1` ~ `A.10` | 10 |
| 后记 | `H-1` ~ `H-4` | 4 |
| | **合计** | **57** |

**未解锁的格子显示什么**：一个暗色方块 + 一颗极暗的 `✦`，不显示标题、不显示剪影轮廓。理由同上——这些 CG 里有 `A.5`（他找到信）、`A.7`（他把额头靠在底座上），提前看见构图就废了。

**建议加一条**：全部 57 张点亮后，回廊标题下方多一行字。这是给通关的人的。至于写什么，你定。

## 七、BGM

`play_bgm("bgm/title.wav")` —— 文件已在 `bgm/title.wav`（40.6 MB）。

**淡入**，约 2 秒。控制台版 `begin_title()` 是静音的（没有 `play_bgm` 调用），所以这是引擎版新增的。

进出规则：

| 情形 | 处理 |
|---|---|
| 启动进标题屏 | `title.wav` 淡入 2 秒，循环 |
| 点「开始旅程」 | 淡出 1.5 秒，切引言的 BGM |
| 点「继续游戏」 | 淡出 1.5 秒，切该层的 BGM（`bgm_chapter[7]`，源.cpp 38） |
| 进「回廊」 | **不切**，`title.wav` 继续放。回廊是标题屏的一部分 |
| 从回廊返回 | 不重头播，接着放 |
| 通关后回到标题屏 | 见下 |

### 通关后的标题屏 —— 已定案

**通关结局A之后，标题屏 BGM 换成 `bgm/titile-hall.wav`（32.5 MB）。**

这个文件源码里从未被调用过，现在派给它这个用处。

| 情形 | BGM |
|---|---|
| 首次启动 / 未通关 | `bgm/title.wav` |
| 通关结局A之后 | `bgm/titile-hall.wav` |
| 进回廊（两种状态都一样） | 不切歌，当前那首继续放 |

**切换的判定**：读通关标记（跟结局A播完的那个 flag 绑定），进标题屏时决定播哪一首。一旦通关，之后每次启动都是 `titile-hall.wav`，不会退回去。

**为什么**：通关的人一定会回标题屏。他看的是同一张封面——同一个天台、同一台望远镜剪影、同一颗最亮的星——但每样东西的意思都变了。这时候换歌，不用一个字就能告诉他：这个封面从来就不是他第一次看到的那个。那五句随机寄语，也是在这一刻才全部生效。

**要注意的一点**：换歌不要做淡变、不要做过渡动画、不要弹「已解锁」提示。就是安安静静地，下一次进标题屏的时候，响的是另一首。玩家自己会发现。发现的那一刻，比任何提示都重。
