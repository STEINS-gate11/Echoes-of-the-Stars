段 1 · 回到桌前 · 认不出自己(约 75 秒)
============================================================

你回到桌前。

台灯亮着——你觉得应该是你自己出门前忘了关的。可是你也不确定,这些天你总是记不清关没关灯,记不清昨晚吃过没吃过晚饭,记不清昨天早上有没有喝那杯速溶咖啡。你觉得这些记不清的事情本身,应该让你慌一下——可是不知道为什么,你并不慌。你只是坐了下来。

椅子发出「吱」的一声。你不记得这把椅子什么时候开始会响的,可是你觉得,应该是很久以前就开始响了——有一些日常的、无关紧要的声音,可能是一直都在的,只是你从前有别的事情要在意,所以听不见。现在没有别的事情了,所以你听见了。

桌上有三样东西——一颗折纸星星,一本没有写过一个字的日记本,一张模糊的照片。

——你抬头看向了对面的墙。

墙上有一面小小的、你自己也不记得什么时候挂上去的镜子。镜子里有一个人。那个人的头发有一点长,有一点乱,眼睛下面有很深的黑眼圈,像是很多年没有睡好一样。那个人看着你,你也看着他。

你花了大概三秒钟,才想起来——那个人是你。

——原来你今夜看起来是这个样子的。

你转过头,把视线从镜子里移开。你不想再看下去。你也不知道从什么时候开始,你已经不太认得镜子里的自己了。可能是从某一天开始的。可能是从上一个月开始的。可能是——从很久以前的某一年,你把手机翻过去、屏幕朝下的那一秒开始的。你今夜什么都记不清。

段 2 · 折纸星星 · 读到字,笑了(约 75 秒)
============================================================

你伸手把那颗折纸星星拿了起来。

它是浅蓝色的,折得很仔细,每一个折痕都压得很实。它比你想的软——像是被人一次又一次拆开过、又折回去,纸的纤维已经软化了。你的手指知道该怎么把它拆开——它先是被从两端捏松,再从底面掀开一层,再从背面拉开一层,最后一层一层展平——你的手指做过这个动作,而且做过很多次,才会这么熟练。

——这就奇怪了。你不记得你自己什么时候学过折星星,更不记得你什么时候做过这个"拆开又折回去"的动作。可是你的手指记得。

你把它拆开了。里面写着一行字:"如果你看到这个,说明你已经准备好了。"

——你笑了。

你笑得很轻,几乎没有声音,只是嘴角微微地动了一下。你不知道你为什么笑——大概是因为,这句话像一个陌生人放在你桌上的、一个奇怪的笑话。**准备好了什么?**桌上有一颗折纸星星、一本没写过字的日记本、一张模糊的照片,和一个镜子里你自己都认不出来的人——这个屋子里没有任何东西,是"准备好了"可以让你去做的。你甚至不知道,今夜之外,还有没有"明天"这种东西,值得让你"准备好"。

字迹很秀气——不是你的字。

你想弄明白,谁会给你留这样一句话,谁会用铅笔写字,谁会把纸折成星星,谁会在写完之后小心翼翼地把它放在你的桌上,让你很多年之后、一个人坐下来的某一晚、把它打开。

你想不起来。

你把那张纸,重新折了回去。你的手指记得所有的折痕。可是你的脑子不记得那些折痕是从哪里来的。

段 3 · 日记本 · 擦掉的字(约 70 秒)
============================================================

桌上还有一本日记本。

封面上写着"给未来的你",字迹和折纸星星里的那一行,是同一个人写的。

你打开日记本。翻到第一页。

——第一页的顶上,有一行淡淡的痕迹。

不是字。是有过字、可是被人擦掉之后剩下的、铅笔的印子。你看得很仔细,想认出来那行字曾经写的是什么。你甚至用指腹去摸那些印子,试图靠触感,把那些擦掉的字重新读出来。

——可是你摸不出来。你也读不出来。

你不记得你什么时候写过一行字在这里。你也不记得你什么时候擦过它。你只是知道——曾经有过一行字。曾经有一个坐在这张桌前、拿着一支铅笔的你——不是你今夜这个坐在这张桌前的你,是从前的、某一个你——写下过一行字,然后又把它擦掉了。

你想过要不要在原来那行字的位置上,重新写点什么。可是你想不出该写什么。你甚至不知道,你重新写下的字,会不会又在你不记得的、某一个明天,被你自己再擦掉一次。

你把日记本合上。你把铅笔放回了笔筒。

你觉得,今夜大概,不是这本日记本的开始。

——也许它,从来就没有过开始。

段 4 · 照片 · 自己身上就是那个味道(约 90 秒 · 最重)
============================================================

桌上还有一张模糊的照片。

照片很旧了,像是很久以前拍的。照片里有两个人的轮廓,站在夜空底下,并肩靠着。你看不清他们的脸——不是因为照片糊,是因为你今夜好像本来就没有能力去看清那两张脸。

其中一个人的肩上,披着一件藏青色的外套。

你看着那件外套,看了很久。你觉得眼熟。你觉得——你见过这件外套。你觉得你知道这件外套是谁的。你觉得你甚至知道,那个人当年穿着这件外套的时候,身上是什么味道——是一种浅浅的、洗过很多次的洗衣皂的味道,混着一点点书页放旧了以后的那种气味,再混着一点点你自己也说不清是什么、可你就是熟悉的东西。

——就在这时,你忽然停住了。

你低下头,看你自己身上穿的那件外套。

——它也是藏青色的。

你抬起自己的手臂,把袖子凑到鼻子跟前,闻了一下。

——洗衣皂。书页。还有那一点点你说不清是什么、可你就是熟悉的东西。

——是你自己身上的味道。

你把手臂放下。你的心脏,今夜第一次,跳了一下——不是"惊",是"钝",像是一个已经很久没用过的机器,忽然想动一下,可是关节都锈住了,动不了。

你不知道你什么时候开始有这件外套的。你不知道这件外套原本是谁的。你甚至不知道——照片里那个人肩上披着这件外套的那一天,是你披的,还是别人替你披的,还是别人披着这件外套走过你的身边,然后过了很多年,那件外套,不知道怎么就到了你的衣柜里,又不知道怎么,今夜就穿在了你的身上。

——你不记得。

你只是知道——你今夜身上的味道,和照片里那个"披着藏青色外套的人"身上的味道,是一样的。

你有可能就是照片里的那个人。你也有可能不是。你今夜连这件事都分不清了。

你把照片放回原位。你的胸口,有一种说不清楚的痛——可是你找不到那种痛的源头。

段 5 · 抬头 · "她"这个字是空的(约 80 秒)
============================================================

你站起来,走到窗前。

你不记得你为什么要走到窗前。你只是觉得,今夜坐得有点久了,应该起来走一走。窗外是七月末的夜,楼下便利店的灯还亮着,一个你不认识的收银员低着头,可能在看手机。街上没有别的人。天空里没有云。

你抬起头。

——有一颗星,比其他所有星都要亮。

你看着那颗星,看了很久。你记得那颗星——你记得它叫什么名字。天琴座 α。中文名叫织女。距离地球二十五光年。这些你都记得。你甚至记得,那颗光是二十五年前从**她**那里出发的,穿过二十五年的空,今晚,才落到你的眼睛里。你甚至记得,二十五年前你三岁,那颗光刚出发的时候,你还是一个不会仰头看星星的小孩,住在这座城市的某一条街上,不知道自己有一天会一个人站在这扇窗前,把这颗光,看这么久。

这些你都知道。

——从**她**那里出发的。

你脑子里冒出了"她"这个字。

你自己也吓了一跳。因为你不知道,"她"是谁。你不知道你为什么会用"她"这个字。你不知道——为什么这颗二十五光年之外的光,应该是从一个"她"那里出发的,而不是从任何别的地方。

你努力去想。你想"她"这个字的意思。你想"她"是不是一个具体的人。你想"她"如果是一个具体的人,那"她"的脸是什么样子,"她"的声音是什么样子,"她"和你之间,曾经发生过什么。

——你脑子里的"她"这个字,是空的。

它就是一个字。一个语法上的字。"她"这个字,今夜对你来说,和"桌子""水杯""七月末的风"这些字,没有任何分别。

——你不知道,为什么这颗星,对你来说,重要。

——你不知道,为什么你今夜看着这颗星的时候,眼眶,会热。

段 6 · 空 · 连"想哭"都不确定(约 65 秒)
============================================================

你在窗前站着,站了很久。

眼眶还是热的。可是眼泪没有掉下来。你也没有出声。你只是站着,看那颗二十五光年之外的光,像一个人在看一份他曾经很熟悉、可是现在读不出内容的文件——你知道这份文件对你重要,你知道这份文件里写着某些你曾经在意过的事情,可是你今夜就是读不出来。

你想哭。

你不知道你为什么想哭。你想哭是因为丢了什么东西——可是你连丢了什么,都想不起来了。你甚至不确定,你今夜的这个"想哭"本身,是真的想哭,还是你只是记得,从前你在这种时候是会想哭的,所以你今夜也应该想哭。

你知道——有些东西,今夜从你这里溜走了。你不知道那些东西是什么,你也不知道那些东西是从什么时候开始溜走的。可能是从今夜开始的,可能是从这三年里的某一天开始的,可能是从更早的、某一年、某一个下午,你把手机翻过去、屏幕朝下、不接电话的那一秒开始的——那次不接电话的事,你还记得,可是你已经想不起来,那时候电话另一头,是谁。

你只是知道——有些东西,应该在的,今夜不在了。

你的胸口那种说不清楚的痛,慢慢地淡下去了。淡到像一杯放在桌上没人喝的水——凉了,还在,可是你已经不记得,为什么倒了这杯水,也不记得这杯水,原本是给谁的。

段 7 · 收尾 · 连"愿望"是什么都不记得(约 30 秒)
============================================================

窗外一颗流星划过。

——你没有许愿。

——因为你不记得,你曾经想向谁许愿。

——你甚至不记得,"愿望"这个词,是什么意思。

【五处最狠的手法】
============================================================

▌ 手法 1 · 镜子里的自己 · 花三秒才认出(段 1)
   身份感崩塌 · 主角连自己是谁都要花时间识别

▌ 手法 2 · 主角笑了(段 2)
   读到"如果你看到这个,说明你已经准备好了" · 反应是笑
   因为这句话对现在的他,像陌生人开的玩笑
   连"该悲伤"都做不到了

▌ 手法 3 · 日记本上擦掉的字(段 3)
   曾经有过一行字 · 被擦掉了
   主角不记得那行字 · 也不记得是谁擦的
   "未来的你" 曾经存在过,但已经消失了

▌ 手法 4 · 主角闻自己身上的味道(段 4 · 最重)
   自己身上的味道 = 照片里那个人的味道
   "你有可能就是照片里的那个人。你也有可能不是。"
   存在感的根本崩塌 · 主角连自己是谁都不确定

▌ 手法 5 · "她"这个字是空的(段 5)
   主角脑子里冒出"她"这个字 · 但不知道"她"是谁
   "她"变成一个和"桌子""水杯"没有分别的空字
   这是最锋利的一击 · 因为"她"是主角一辈子记得最深的字

【消散动画技术实现思路】
============================================================

▌ 遍历双向链表
   conver_node* p = head;
   while (p != NULL) {
       // 显示物品名字
       gotoxy(x, y);
       setColor(6);
       printemoji(p->name);
       Sleep(1500);

       // 字符逐个消散
       int len = wcslen(p->name);
       for (int i = 0; i < len; i++) {
           gotoxy(x + i * 2, y);
           setColor(8);
           printemoji(L"·");
           Sleep(150);
       }
       Sleep(500);

       // 完全清空
       gotoxy(x, y);
       for (int i = 0; i < len * 2; i++) {
           printf(" ");
       }
       Sleep(500);

       p = p->next;
   }

▌ 视觉设计
   - 深黑背景
   - 物品名字用暖色(6 深黄)
   - "·" 用冷色(8 灰)
   - 完全消散后 · 用空格覆盖 · 一秒静默 · 下一件

▌ 时长
   - 每件物品 · 约 3~4 秒
   - 15 件 · 约 50 秒总时长
