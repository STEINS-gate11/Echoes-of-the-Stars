============================================================
【设计原则】
============================================================

▌ 独角戏
   B 是「独角戏」· 主角一直在书房里
   段 4 "走到窗前"其实主角也没真动 —— 只是抬头看
   段 5 "折回去"发生在原地
   全程画面变化极少 —— 呼应"什么都没发生"

▌ 复用 draw_ending_study(int mode)
   共用 A/B/C 书房布局
   mode=1 · 冷色 · 灰白为主
   相对于 A 的暖色(暗中带金)· B 是"心已经凉了"的冷

▌ B 独有的两个元素
   · 茶印子 o · 在 @ 的左边一格(x=25 y=14)· 灰 8
   · 织女星 ✦ 静止不呼吸 · 灰 8(A 是呼吸 · C 是极暗)

▌ 玩家选择的 4 个细节(2026-07-30 确定)
   1. 段 4 @ 不移动 · 只播独白
   2. 段 2 ⭐ 变成展开的纸 ─ · 段 5 折回去 ─ 变回 ⭐
   3. 段 6-7 结尾 · 整个书房变暗一档
   4. 窗户底部加一颗 . (便利店灯)

【B 段落动画流程】
============================================================

段 1 · 回到桌前(约 60 秒)
─────────────────────────────
  · 场景全画 · mode=1 冷色
  · @ 出现在 (26, 14)
  · 茶印子 o 已在 (25, 14)
  · 织女星 ✦ 静止 · 灰 8
  · 便利店灯 . 在 (37, 4)
  · 独白播「你回到桌前。台灯还亮着...」
  · 按空格继续


段 2 · 拆星星 · 读到字 · 却没得到什么(约 80 秒)
─────────────────────────────
  · 独白播「你伸手把那颗折纸星星拿了起来...」
  · 屏幕变化:
      x=23 y=11 的 ⭐ · 缓慢变化
      步骤 A · ⭐ → ✧(半展开)· 停 500ms
      步骤 B · ✧ → ─(展开的纸)· 灰 8
  · 独白播「纸上写着:"如果你看到这个,说明你已经准备好了。"」
  · 独白播「你以为你会哭 · 你没有」
  · 按空格继续


段 3 · 日记本 · 一个字也没写(约 80 秒)
─────────────────────────────
  · @ 保持在 (26, 14)
  · 桌面不变(⭐ 位置还是 ─ 展开的纸)
  · 独白播「你打开那本空白的日记本...」
  · 独白播「你在纸上一个字也没写」
  · 按空格继续


段 4 · 抬头 · 说不出口(约 70 秒)
─────────────────────────────
  · @ 不动 · 保持在 (26, 14)
  · 独白播「你站起来,走到窗前」(文字里主角起身 · 画面里不动 · 反差)
  · 独白播「你抬起头。天琴座 α...」
  · 织女星 ✦ 保持静止(不呼吸 · 灰 8)
  · 独白播「你想说'你看,我来了' · 可是这句话你今夜说不出口」
  · 按空格继续


段 5 · 折回去 · 因为你还要活下去(约 75 秒)
─────────────────────────────
  · 独白播「你把那张展平的纸重新拿起来...」
  · 屏幕变化:
      x=23 y=11 的 ─ · 缓慢变化
      步骤 A · ─ → ✧(半折起)· 停 500ms
      步骤 B · ✧ → ⭐(折回星星)· 冷灰 8
  · 独白播「桌上三样东西 —— 一颗折纸星星,一本没有写过一个字的日记本,一张模糊的照片。和你今夜走进这间书房的时候,一模一样。」
  · 按空格继续


段 6 · 你会照样过下去(约 85 秒)
─────────────────────────────
  · 屏幕变化:整个书房变暗一档
      · 所有字符颜色 -1(6 → 8 · 7 → 8 · 8 保持)
      · 除了 @ 和织女星 · 都变暗
  · 独白播「什么都没有发生过...」
  · 独白播「你会照样过下去。不是因为你想过,是因为你得过。」
  · 按空格继续


段 7 · 收尾 · 未完待续(约 50 秒)
─────────────────────────────
  · @ 不移动 · 但颜色再暗一档(7 → 8)
  · 独白播「台灯还亮着。你没有关它。」
  · 独白播「你只是把手放在了桌上那颗折纸星星旁边...」
  · 独白播「不是今晚。可是明天你还是要过下去,哪怕下一次未必会来。」
  · 停 3 秒
  · @ 不淡出 · @ 保持不动 · 屏幕整体保持
  · 淡出转黑(整个画面一起暗下去 · 直到全黑)


============================================================
【关键节点强化】
============================================================

▌ 段 2 · ⭐ → ─ · 拆开的动作
   玩家看到 ⭐ 变成 ─ · 有"打开了"的期待感
   然后独白告诉你"你没得到什么" —— 反差

▌ 段 5 · ─ → ⭐ · 折回去的动作
   玩家看到 ─ 变回 ⭐ · 意识到"回到了原点"
   桌面和段 1 完全一样 —— "什么都没发生"

▌ 段 6 · 整个书房暗一档
   前面 5 段都是同一个亮度 · 段 6 突然暗一档
   玩家感觉"世界褪色了" —— 呼应"想过 vs 得过"

▌ 段 7 · 淡出转黑 · 不是 @ 淡出
   A 的段 20 是 @ 淡出(主角走了)
   B 的段 7 是全屏淡出(主角还在 · 只是屏幕关了)
   —— 主角明天还要过下去 · 只是玩家看不到了

【代码思路】
============================================================

▌ 共用绘制函数
   void draw_ending_study(int mode);
   · mode=0 → A 暖色
   · mode=1 → B 冷色
   · mode=2 → C 暗色
   · 函数内部根据 mode 选颜色表

▌ B 专用元素
   void draw_B_extras(void) {
       gotoxy(25, 14); setColor(8); printf("o");   // 茶印子
       gotoxy(37, 4);  setColor(8); printf(".");   // 便利店灯
   }

▌ 段 2 · ⭐ → ─ 动画
   void unfold_star_B(void) {
       gotoxy(23, 11); setColor(8);
       printemoji(L"⭐"); Sleep(500);
       gotoxy(23, 11); printf("  ");   // 擦
       gotoxy(23, 11); setColor(8); printemoji(L"✧"); Sleep(500);
       gotoxy(23, 11); printf("  ");   // 擦
       gotoxy(23, 11); setColor(8); printf("──"); // 展开
   }

▌ 段 5 · ─ → ⭐ 动画
   void refold_star_B(void) {
       gotoxy(23, 11); printf("  ");
       gotoxy(23, 11); setColor(8); printemoji(L"✧"); Sleep(500);
       gotoxy(23, 11); printf("  ");
       gotoxy(23, 11); setColor(8); printemoji(L"⭐");
   }

▌ 段 6 · 整个书房暗一档
   void dim_scene_B(void) {
       // 全屏重画 · 用更暗的颜色表
       // 每个色号 -1 · 但 8 保持 8 · 保持最低亮度
       // 主角 @ 从 7 变 8
       // 织女星保持 8(不变)
       draw_ending_study(1);  // 已经是 mode=1 · 但用一个 dim 变体
   }

▌ 段 7 · 全屏淡出
   void fade_out_all(void) {
       for (int step = 0; step < 5; step++) {
           // 每步整个屏幕降一档亮度
           // 8 → 8 → 0 · 逐步降
           Sleep(400);
       }
       system("cls");  // 最终清屏
   }
