# 星空回响 · Echoes of the Stars

![标题画面](cg/titile.png)

> "如果你看到这张纸条，说明你已经忘了。"

一个用 **C++ + Windows 控制台** 写成的交互叙事游戏。纯 ASCII 字符作画、打字机叙事、全程原创配乐，在黑底白字的终端里讲一个关于失忆、寻找与告别的故事。

C 语言大程序设计课程作业，2026 年。

## 游戏简介

深夜，我在书房醒来，不记得自己为什么坐在这里。

桌上有三样东西：

- 一颗磨破了角的折纸星星
- 一本一个字都没写过的日记本
- 一张模糊的照片——两个人的轮廓，其中一人肩上披着藏青色的外套

我知道我忘了一个人，却说不出她的名字。

跟随着五层记忆场景，玩家将走过与 **Vega** 初遇的图书馆、并肩看过星空的天台、无力挽留的医院、独自缺席的天文馆，最终回到书房，决定这段记忆的结局。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动光标 |
| `E` | 与物品交互 / 推进对话 |
| `B` | 回看对话历史（双向链表，`A` / `D` 翻页） |
| `Q` | 返回上一层 / 退出 |

每层场景藏有 3 件物品（2 件显性、1 件隐藏），全部场景共 **15 件**。
拾取与遗漏会改变"记忆值"，最终导向不同的结局。

## 章节与结局

- 标题 → 引言 → 序幕 · 深夜书房
- 五层记忆：图书馆 · 天台 · 医院 · 天文馆 · 回响
- 三个结局 + TE：
  - **结局 A · 星光彼岸**（街道 → 楼梯 → 天台，含流星动画与后记）
  - **结局 B · 未完待续**
  - **结局 C · 星尘归海**（含消散动画）
- Vega 支线、献词、章节过场

## 技术实现

- Win32 控制台 API：`gotoxy` 定位、彩色输出、光标隐藏、局部重绘防闪烁
- `WriteConsoleW` 宽字符打字机，正确处理中文与 emoji 代理对
- `PlaySoundA` 异步循环播放章节 BGM
- 场景文件运行时加载：20×48 纯 ASCII `.txt` + 碰撞集判定
- **双向链表**实现对话历史，**栈**实现时间回溯，状态机驱动章节流转
- 记忆值系统与结局冻结机制；纯 C 风格结构体 + 函数，无第三方依赖

## 编译与运行

环境：**Windows + Visual Studio 2022**（Community 即可），源码为 UTF-8 with BOM。

1. 打开 `Project2.sln`
2. 选择 `x86` 配置（Debug / Release 均可）
3. 在 Visual Studio 中运行（`F5` 或 `Ctrl+F5`）

> 注意：场景 `.txt` 与 `bgm/` 文件夹位于 `Project2/Project2/` 下，
> 游戏以 VS 的工作目录（`$(ProjectDir)`）读取它们。
> 若直接双击 exe 运行，请把 8 个 `.txt` 和整个 `bgm/` 文件夹放到 exe 同级目录。
